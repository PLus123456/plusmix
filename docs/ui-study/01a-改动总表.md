## 0. 读法与口径

- 输入：9 份区域报告的 C 节（R8 取 B、C 两节），共 217 条来源条目：R1 22、R2 25、R3a 28、R3b 28、R4 21、R5 7、R6 19、R7 18、R8-B 11（C01–C11，外加 B 节末一段）、R8-C 38（U01–U38）。之后按核对报告 VF1–VF5（代码：VF1 / VF3 / VF5；截图：VF2 / VF4）改了事实，并把核对时新发现、属于菜单 / 按钮逻辑的问题并进来（编号记作"VF1-新n""VF3-Nn"）。
- 合并结果：**130 条统一条目**（A–P 16 区），另 30 行"有意保留的差异"。每条来源的去处见第 6 节；核对改了哪些说法见第 7 节。
- 列的意思：
  - **参考依据**：参考软件截图的图号；界面稿写"界面稿 L行号"（界面稿是 docs/spec/ui-mock/ 下的 .dc.html，文件名含竞品名，这里不写全）。
  - **现状证据**：挑一处最直接的 文件:行号（相对仓库根）。核对报告核过的写"（VF1 核）"之类；本次汇总时回仓库看过的写"（已核对）"。
  - **来源条目**：合并进来的编号；一条来源只贡献了一部分时写"（某某部分）"；不属于 C 节的编号写"旁证"。
  - **优先级**：P0 = 操作员每场都用、现在找不到或和习惯相反；P1 = 常用但有绕过办法；P2 = 少用或锦上添花。来源不一致时取最高，差别写在"分歧与待定"。
  - **工作量**：S ≤ 半天，M 1–3 天，L > 3 天。R8 和 VF 报告不估工作量，标"（R8 未估）""（VF 未估）"的是汇总时按改动面定的。
  - **契约**：否 / 是（要走 docs/contract-changes/ 提案）/ 待定（取决于选哪个方案）/ 可选（只改界面不用，顺带收口才要）。
- 参考截图的读法（VF2、VF4 的全局结论，本表"参考依据"已按此改写）：
  - 截图里的"默认"只说明截图当时的值：那台机器被改过（分类起过中文名、加过快捷键），一律写"截图时"。
  - 灰字不等于禁用：同一种控件字体里，不含空格的字渲染成灰色衬线字、含空格的是黑色等宽字；主界面按钮上含空格的字显得粗。判断禁用要看控件本身。
  - "模态 / 非模态""单选""点主体执行""键入毫秒""按钮字 = 当前效果"之类，截图都没演示，标"（推测）"。
  - 底栏只有一级菜单和弹出层朝上；子菜单（图 123 的 SRT ▸）往下伸、会压住底栏按钮。窗口上半部的 ▾ 菜单都往下开、左缘对齐主体按钮。
- 已定项不当新缺口：PGM 红 / PVW 绿（落地方案 §7 第 3 条）；转场集合 Cut / Fade / Wipe / Zoom / Stinger，不做 Merge / Fly / Quick Play（§7 第 2 条）。T-bar 竖放**不在** §7 表里，是 W2-B 的实现选择（reports/w2-app.md:123），改横放要用户定（见 C7）。
- 给 App 的文案一律是我们自己的说法；参考软件的标签只在"参考依据"里当证据。

**报告之间的事实冲突（已核对）**

1. **转场列 Overlay 按钮在通道没指定输入时的现状**（C6）。R3a-M11："通道没指定输入时开了也看不到画面"。R8-U15："按了无效，只给提示"。核对：App/Sources/UI/TransitionPanelView.swift:194-198 永远发 `overlay(channel, on: !on, input: nil)`；Packages/SwitcherCore/Sources/SwitcherEngine/State/MixerReducer.swift:127-142 在 input 为 nil 时照样把 `on` 翻成真，按钮变蓝；所谓"提示"是固定的悬停文字（App/Resources/zh-Hans.lproj/Localizable.strings:696）。R3a 准确，R8 的"按了无效"不准（VF1 同结论）。
2. **T-bar 竖放是不是"已定"**（C7）。R8 C 节开头说 W2-B 的差异表"已按落地方案 §7 定掉三件：……T-bar 竖向"，R8-U16 标"已定"。核对：落地方案 §7 决策表（docs/plan/导播台落地方案.md:209-222）只有转场集合（第 2 条）和 tally 颜色（第 3 条），没有 T-bar 方向；竖放只出现在 reports/w2-app.md:123，是 W2-B 自己的实现选择。R8 的说法不准。
3. **效果链到底接没接**（J1）。R4-G27 写"静态看可能根本没接进混音（存疑）"、P1；R6-M02、R8-S18 / S19 写引擎不读、P0。核对：Packages/SwitcherAudio/Sources/Integration/AudioEngine.swift:463-489 的 applySettings / applyBuses 只落增益、静音、独听、声像、路由、延迟，不读 effects；VF3 另查 installEffect 等在生产代码里零调用。R6 / R8 准确，R4 的"存疑"可以去掉。

不算冲突的一处：tally 颜色，R3a-M27 引"落地方案 §1.3 第 3 条"，R8-U12 引"§7 第 3 条"。两处都存在（docs/plan/导播台落地方案.md:36 列冲突、:215 是决策），说的是同一件事。
