# R8 规格对照实现（我们自己的规格 + 界面稿）

范围：设计方案 §1.2、§5–§10 逐条拆成功能点，对照 App/、Packages/*/Sources/、Tools/ 的代码（以代码为准，报告 / 文档作旁证）；界面稿 docs/spec/ui-mock/vMix for Mac.dc.html（下文"稿:行号"指这个文件的行号）逐个控件对照；后续方案里已经部分落地的条目。
证据一律"文件:行号"（相对仓库根）。树 = c836cce（本 worktree，只读）。

先说结论（细节在各节）：
- **最严重的一条**：每路 EQ / 压缩（§1.2 音频）和四条总线的效果链，界面上有完整编辑器、状态机也收命令，但音频引擎根本不读——`AudioEngine.applySettings / applyBuses` 只落增益 / 静音 / 独听 / 声像 / 路由 / 延迟（Packages/SwitcherAudio/Sources/Integration/AudioEngine.swift:463-489），`installEffect / installStandardEffects` 只有单元测试在调。用户手册 docs/user/概念.md:78 还写着"四条总线各有…效果链"。（R8-S18 / S19）
- 界面只能"一起起停全部录制 / 全部推流"，没有单路起停，也看不到每个推流目的地的状态；转场类型只能"选了就执行"，T-bar 想推 Wipe 必须先真做一次 Wipe。（R8-S11 / S29 / S34，B 节 C01–C03）
- App 没起独立的 tally 流服务（只有 headless 有 `--tally-port`），但用户手册和 integrations 文档都按 App 能接 tally 灯写。（R8-S40）
- 文件输入的暂停 / 重播 / 定位 / 运行中改循环，引擎层 `FileInput` 早就有接口，契约没命令、界面没入口；改"循环"只能重建这一路。（R8-S04，B 节 C11，C 节 U24）
- 界面稿里的输入分组 / 颜色标签、格子齿轮、顶部工具条这批，W2-B 当年写"留给 W3-E"（reports/w2-app.md:112-130），W3-E 的 prompt 没列（docs/plan/prompts/54-W3E-界面二期.md），落空了。

计数：A 节 51 项——已做 31、部分 16、没做 2（都是效果链）、只有 API 2；B 节 11 条（其中 2 条契约连命令都没有）；C 节 38 行，去掉已定不改的 3 行和无缺口的 1 行，实际缺口 34 个；D 节 12 条后续方案已部分落地。

## E. 需要用户拍板的问题

1. **E1 效果链现在"界面能调、声音不变"，0.1.0 怎么处理？** 选项：(a) 发布前接上总线效果——C 端每总线已有 EQ → 压缩 → 限幅三格（sw_audio_rt.h:68、sw_mix.c），只差 AudioEngine 把 BusState.effects 映射成 installEffect / setParameter，M；(b) 每路 EQ / 压缩要在 C 混音器里加每路效果格，L；(c) 做不完的先在编辑器上标"未生效"或隐藏。**倾向**：总线走 (a)（Master 限幅是推流每场都要的），每路走 (c) 并排进下一轮；另外要定"界面 3 段 EQ ↔ C 端 1 个 EQ 格"怎么对（多装 EQ 格或换多段 EQ 单元）。
2. **E2 "只选转场类型不执行"放哪？** 每个按钮加 ▾，还是 T-bar 上方那行"T-bar：Fade"改成弹出菜单？**倾向**后者：离 T-bar 最近、不加按钮宽度；Wipe / Stinger 的参数 ▾ 仍放在各自按钮上（U14）。
3. **E3 文件播放控制进不进 v1？** 要新命令（改契约）：播放 / 暂停 / 从头播 / 设循环（+ 可选定位）。**倾向**进 v1 的最小集，外加每路"切到 PGM 时从头播"开关（也是契约字段）；播放列表仍按后续方案 §2.5。理由：开场视频从头播是每场都用的，现在只能靠重建输入。
4. **E4 FTB 时长**：新增命令（改契约），还是改成跟随转场时长？**倾向**新增命令 + FTB 按钮 ▾；跟随转场会让"慢渐黑 + 快切"的常见组合做不到。顺手改 docs/user/概念.md:63。

7. **E7 转场列 Overlay 按钮在通道空着时的行为**：**倾向**采用界面稿的"空通道 = 用当前 PVW 输入打开"，非空通道仍只开关、不清空设置（清空会丢掉位置 / 动画）。
