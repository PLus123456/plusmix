# 弹出菜单 / 弹出层几何（巡检实测）

坐标：Cocoa 全局坐标（点，左下原点；主屏 = 内建屏 1728×1117 在 (0,0)，LG ULTRAGEAR 2560×1440 在 (-398,1117)，巡检窗口都放在 LG 上，1×）。
「伸出下沿」= 主窗口 frame.minY − 弹出物 frame.minY（>0：弹出物伸到窗口下沿以下这么多点）；「伸出上沿」= 弹出物 maxY − 窗口 maxY（>0：伸到窗口上沿以上）。
菜单窗口的 frame 取自 CGWindowListCopyWindowInfo（层级 101），弹出层取 NSApp.windows 里的 _NSPopoverWindow（含箭头与留白），sheet 取 sheet 窗口。
拼图（*-composite.png）：底图 = 主窗口截图、按窗口服务器给的边界贴上弹出物截图，窗口外是浅灰棋盘格；红框 = 主窗口 frame，红虚线 = 窗口下沿，青框 = 弹出物，标签写尺寸与超出量。
窗口位置：1440x900 = content 1440×900 在 LG visibleFrame 居中（下方留 239 pt 屏幕）；1100x700 = frame 1100×700 居中（下方 355）；1100x700-top = 贴屏幕上沿（下方 710）；builtin-full-1728x994 = 内建屏铺满的尺寸、下方留 90（= 内建屏 Dock）；visible-2560x1410 = 铺满 LG（窗口下沿 = 屏幕下沿）。

## 要点

- 底栏「外部输出」菜单（原调用 `menu.popUp(positioning: nil, at: NSPoint(x: 0, y: anchor.bounds.height), in: anchor)`，NSButton.isFlipped == true → 这个点是按钮 frame 的左下角）：菜单窗口顶边比这个点高 5 pt（菜单内边距），往下挂 58 pt → 窗口下沿以下 **25 pt**（1440x900 / 1100x700 / 1100x700-top / builtin-full 四种位置都是 25）；键盘打开的显示器子菜单 340×261 与父项顶对齐 → 窗口下沿以下 **228 pt**。
- 窗口下沿贴屏幕下沿时（visible-2560x1410）系统把菜单往上推：菜单在窗口内（伸出 −6），但盖住了「外部输出」按钮本身。run 2 那次"没弹出来"是巡检时 App 失去了前台（窗口标题灰），run 3/4 各复测两次都正常弹出。
- 往上弹的写法 `at: NSPoint(x: 0, y: -menu.size.height + 1)`：菜单底边在按钮上沿之上 4 pt，整块在窗口内（伸出 −56）；但子菜单仍从父项往下长 → 窗口下沿以下 **147 pt**。把显示器子菜单拍平成段标题后（2 台显示器 × 6 路输入 = 25 项，340×571）往上弹，整块在窗口内（上方还剩 305 pt）。
- 底栏「叠加…」弹出层（`preferredEdge: .maxY`，翻转坐标的按钮上 .maxY = **下沿**）：屏幕下方放得下就往下弹——1100x700 / 1100x700-top 两处弹出层整块在窗口外，伸出下沿 **318 pt**；放不下（1440x900 下方只有 239、builtin-full 只有 90、铺满 0）才翻到上方。
- 「叠加…」弹出层尺寸：窗口 346×346、内容只有 **320×320**，而 SwiftUI 表单是 400×640 → 左右各被裁 40、上下各 160，每行标签头一两个字被切掉（"动画"→"画"、"PVW 预览"→"VW 预览"、"Overlay 2"→"verlay 2"）。原型给 `preferredContentSize = 400×640` + `.minY`：1440x900 弹出层 426×666 在按钮上方、整块在窗口内（上沿还剩 214）；1100x700 时伸出窗口上沿 **18 pt**；400×520 时在窗口内（上沿还剩 102）。
- 「参数…」弹出层（.maxX）在按钮右侧、三种尺寸都在窗口内；右键菜单、sheet、重命名对话框都在窗口内。
