## A. 参考软件：入口与菜单逻辑

### A1 主窗口右上角按钮组（图 001、图 002）

- 位置：标题栏下面那条深色工具条的最右端，从左到右四个："Pause Inputs"｜"Basic"｜"Settings" 带右侧窄条"▾"（同一个按钮分成两段）｜"?"（小方块）。同一条工具条左端是 Preset 组（New / Open▾ / Save / Save As▾ / Last），中间是"Fullscreen▾"，不在本区（图 001）。
- "Pause Inputs"：普通按钮；字体比旁边两个粗（图 001、002 都这样），看不出是不是"已按下"状态。截图没有演示点下去的效果。（推测）两种可能：暂停所有输入的播放 / 采集，给排练或改设置时省资源；或者暂停媒体类输入的播放。要到 Windows 机器上看悬停提示才能定（见 E-4）。
- "Basic"：普通按钮。（推测）切到简易界面模式。依据：Options 页有"Start in Advanced mode"且默认勾上（图 005），说明主界面有 Basic / Advanced 两种模式，按钮上的字是"要切去的那个模式"。
- "Settings" 主体：左键。（推测）打开 Settings 窗口；打开哪一页没截到（图 003 是从 ▾ 菜单点"Display"进去的，图 004–021 是在窗口左侧导航里点的，鼠标都停在导航项上）。

### A2 Settings 窗口的外框（图 003–021 共用）

- 独立窗口，标题"Settings"，右上只有关闭 ×。（推测）是模态对话框，因为底部是 OK / Cancel。
- 左侧深色导航栏：16 页，顺序和 ▾ 菜单完全一样，也没有分组 / 分隔；当前页绿底高亮；单击切页。
- 左下三个按钮："Import"｜"Export"｜"Default"。（推测）导入 / 导出整套设置、恢复默认。
- 底栏左："Show Advanced Settings" 复选框，默认不勾；底栏右："OK"｜"Cancel"。（推测）OK 才生效，Cancel 全部放弃。
- 勾上"Show Advanced Settings"会弹模态确认框（图 022）：标题是"<产品名> Advanced Settings"，问号图标，大意"高级设置只应在官方支持人员指导下修改，是否继续？"，按钮"是(Y)"｜"否(N)"（系统语言的按钮）。点"是"之后出现什么没截（用户在这里停了）。

### B4 第 3、4、6 问的直接回答

- **第 3 问（Display 页三样在我们这里怎么改）**
  - 节目格式：PlusMix › 偏好设置…（⌘,）› 节目格式，分辨率 3 档 + 帧率 7 档，点"应用格式（重起引擎）"（PreferencesPanel.swift:173-185）。格式存在节目文件里（MixerState.format），"应用"= 带着输入 / 输出换一个引擎（AppController.swift:154-160）：录制 / 推流被停、所有设置窗被关、事先不确认。另一条路是改节目文件再打开。
  - 主题：没有，强制深色（AppDelegate.swift:29）；PVW / PGM 颜色写死绿 / 红（Theme.swift:13-16）。
  - 缩略图尺寸：没有，固定 200×112.5、24 fps（Theme.swift:25-26；InputCellView.swift:29）。
  - 同一页的"Fullscreen"那一块在我们这里是输出设置 › 外部显示（每块屏一路）+ 偏好设置 › 外部输出（主屏层级）。
- **第 4 问（输出类几页与我们输出设置 / 偏好设置的关系）**
  - "Outputs / NDI / SRT" ≈ 输出设置里"外部显示 + NDI 发送 + 多画面布局"三页合起来，外加一张我们没有的"每路来源 / 叠加"总表；SRT 在我们这里只是推流目的地的一种地址。
  - "External Output 1–4" ≈ 输出设置 › 虚拟摄像头（第 1 页默认勾的那一项）；硬件输出我们没有。参考把屏幕全屏放在 Display 页，我们放在"外部显示"，名字还叫"外部输出"（见 M19）。
  - "Recording" ≈ 输出设置 › 录制 › 文件一节（目录、文件名模板）；参考是全局一套，我们是每个节目的录制输出各一套；磁盘下限 / 备用目录没有界面（M09）。
  - "Audio" 页的东西在我们这里散在调音台头（AFV、PFL / AFL）、输入设置（延迟补偿）；偏好设置 › 节目音频（对齐延迟、监听点）是我们多出的。
  - "Audio Outputs" ≈ 偏好设置 › 音频输出，只能选一台设备，声道写死（M20）。
- **第 6 问（右上角三个按钮）**：Pause Inputs、Basic、? 都没有对应物；主窗口顶部根本没有工具条（MainWindowController.swift:127-136），帮助菜单只有诊断两项（AppDelegate.swift:153-158）。三者的行为推测见 A1，是否做见 E-4、E-5、E-10。

## E. 需要用户拍板的问题

1. **要不要把 4 个设置窗合成一个带侧栏的「设置」窗？** 倾向合：参考和界面稿都是一个入口；输出设置本来就是侧栏形态，主要是装配工作。侧栏分"本节目 / 本机"两组，页头写明保存位置，避免"改了设置、换个节目又没了"的误会。
2. **提交方式：照参考的 OK / Cancel，还是 mac 的即时生效？** 倾向即时生效（macOS 设置窗的惯例，输出设置现在就是这样），只把要重起引擎的项集中到一个"应用并重起引擎"按钮，并在录制 / 推流进行中先确认。
3. **工具条做在标题栏（NSToolbar）还是像界面稿那样在窗口内单独一行？** 倾向 NSToolbar 统一样式：原生、全屏时行为正确、省一行高度；内容和界面稿一样（左节目组、中外接屏、右设置组）。左、中两组由负责节目文件 / 外接屏的调研定。
4. **"暂停全部输入"要不要做、做成什么？** 截图看不到它的行为。请在 Windows 机器上把鼠标停在"Pause Inputs"上看提示，或在一个不直播的预设里点一次，看是暂停媒体播放还是暂停采集。倾向 v1 不做、也不放占位按钮。
5. **简易模式要不要做？** 倾向后续再做：教会志愿者场景有价值，但 v1 先把完整界面理顺；工具条先不放"简易"按钮。
6. **录制 / 推流确认的默认值**：倾向"停止前确认"默认开、"开始前确认"默认关；快捷键 / MIDI / API 一律不弹（外设要确定性）。
7. **App 里起只读 tally 流，默认开还是关？** 倾向默认关，打开时监听局域网并显示地址。理由：默认不对外开端口；教会 / 学校现场要用时一个开关就够。
8. **防睡眠 / App Nap 默认开？** 倾向开：直播机本来不该睡，W4-A 实测过空闲时实时线程会被拖慢；显示器休眠单独给开关、默认也阻止。
9. **菜单名"偏好设置…"改成"设置…"？** 倾向改（macOS 13 起的标准叫法，我们最低 macOS 15）。
10. **帮助入口开什么？** 倾向随包带手册（导播现场常没网）；要定用 HTML 还是 PDF、谁负责从 docs/user 生成（W4-C 的文档归属）。
11. **隔行 SDI 源（1080i50 / 59.94）要不要在 v1 去隔行？** 倾向不进 v1、列进后续；v1 先在 DeckLink 输入上提示"隔行信号，未去隔行"。
12. **提醒（没在录 / FTB 开着 / 音量低）进不进 v1？** 倾向进一个小版本：只在主窗口里提醒（标题条或底栏变色），不改契约；多画面叠提醒跟后续方案 §3.6 一起做。
