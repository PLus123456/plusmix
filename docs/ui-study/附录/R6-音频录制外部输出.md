### B4 效果编辑器与引擎现状
- 编辑器（App/Sources/Settings/EffectChainView.swift:9-53；键表见 App/Sources/Settings/AudioEffectParams.swift:1-7 与 docs/CONTRACTS.md:139-147）：
  - "参数均衡（ParametricEQ，最多 3 段）"：
    - 每段：启用 / 中心频率 20–20000 Hz / Q 0.1–10 / 增益 −24…+24 dB / "去掉这段"。
    - "加一段"，新段默认 1000 Hz、Q 1、0 dB（App/Sources/Settings/EffectChainView.swift:17-24；App/Sources/Settings/AudioEffectParams.swift:42-48、73）。
  - "压缩（DynamicsProcessor）"：
    - 两个开关："用压缩" + "启用"。
    - 阈值 −60…0（默认 −20）、Headroom 0.1…40（5）、扩展比 1…50（2）、起音 0.1–200 ms（1）、释放 10–3000 ms（50）、输出增益 ±40（0）（App/Sources/Settings/EffectChainView.swift:26-37；App/Sources/Settings/AudioEffectParams.swift:49-58）。
  - "限幅（PeakLimiter）"：
    - 两个开关："用限幅" + "启用"。
    - 起音 1–30 ms（12）、衰减 1–60 ms（24）、预增益 ±40（0）（App/Sources/Settings/EffectChainView.swift:38-46；App/Sources/Settings/AudioEffectParams.swift:59-65）。
  - "其他效果（原样保留）"（App/Sources/Settings/EffectChainView.swift:47-53）。
  - 没有：噪声门、图示 EQ、"比例"、复位、窗内电平表。
- SwitcherAudio 包：
  - 每条总线固定三格苹果 AU，顺序 EQ → 动态 → 限幅（Packages/SwitcherAudio/Sources/SwitcherAudio/AudioMixer.swift:21-23；Packages/SwitcherAudio/Sources/SwitcherAudio/BusEffectChain.swift:72-78、111-114；Packages/SwitcherAudio/Sources/CSwitcherAudioRT/sw_mix.c:793-800）。
  - 有类型化的 setter（Packages/SwitcherAudio/Sources/SwitcherAudio/BusEffectChain.swift:130-153）。
  - 每路输入没有效果槽。
- 苹果 AU 的参数范围（SDK AUParams.h）：
  - AUParametricEQ 是**单段**：中心 20 Hz…Nyquist、Q 0.1–20、增益 ±20 dB（:436-446）。
  - AUDynamicsProcessor：阈值 −40…+20 dB；没有固定"比例"，压缩量由 Headroom 决定（:460-494）。
  - AUPeakLimiter：起音 1–30 ms、衰减 1–60 ms、预增益 ±40 dB（:448-458）。
  - 另外还有 AUGraphicEQ（10 / 31 段，:788-792）和 AUNBandEQ（多段，每段可选滤波类型，:572-593、683）。
  - 所以：编辑器的阈值下限 −60、EQ 增益 ±24 都超出 AU 范围；编辑器能加 3 段 EQ，但每条总线只有 1 个单段 EQ。
- **没接线**：
  - 集成层从不装 AU，也不读 effects。applyBuses 只设增益 / 静音（Packages/SwitcherAudio/Sources/Integration/AudioEngine.swift:479-489）；applySettings 只设增益 / 静音 / 独听 / 声像 / 路由 / 延迟（Packages/SwitcherAudio/Sources/Integration/AudioEngine.swift:464-477）。
  - 报告里写得很清楚："音频引擎暂不读效果"（reports/w3-app2.md:56）；效果参数映射列为后续（reports/w2-audio-integ.md:130）。
  - 用户手册却写"四条总线各有增益 / 静音 / 效果链"（docs/user/概念.md:78）。
  - 结果：现在调 EQ / 压缩 / 限幅，听不出任何变化。

### B6 外部输出
- 入口：底栏"外部输出"（普通按钮，提示"外部显示：每块屏 × 来源"）左键 → presentExternalMenu（App/Sources/UI/BottomBarView.swift:43、56、227；App/Sources/UI/MainWindowController.swift:147、295-298）。
- **弹出方向（代码事实）**：
  - 调用是 `menu.popUp(positioning: nil, at: NSPoint(x: 0, y: anchor.bounds.height), in: anchor)`，anchor = 这个 NSButton。
  - NSButton 用 flipped 坐标（isFlipped == true，调度方已确认），所以 y = bounds.height 是按钮**底边**。
  - popUp 把菜单左上角放在这个点，菜单就从按钮左下角**往下**展开：盖住底栏下半的状态行，再伸出窗口底边（屏幕底部放不下时由系统挪位）。

- 菜单栏 输出 › 外部输出 ▸ 挂的是同一份菜单，每次打开"输出"菜单时重建（App/Sources/AppDelegate.swift:124-128、259-264）。
- 菜单树（App/Sources/UI/ExternalOutputMenu.swift:47-91）：
  - 没有显示器时：一行灰的"（没有显示器）"。

  - 已有外部输出时：─── / 每路一项"关闭 n <名字>（状态）" / "关闭全部外部输出"。

## E. 需要用户拍板的问题

1. **要不要引入"输出通道"（参考 Output 2–4 那种：先选通道，再由通道选源）**
   - 选项 A（倾向）：v1 不加通道。每个输出继续自己存 source。
     - 界面上把"每块外部显示"做成通道式单选菜单（R6-M14）。
     - 录制配置各自有来源下拉（R6-M08）。
     - 干净 PGM、录 / 推 PVW 或多画面，留给后续方案 §3.6 去扩 OutputSource。
   - 选项 B：加"Aux 通道"。
     - 契约：MixerState 加 `aux: [AuxChannel]`（编号、source、带不带叠加）；OutputSource 加 `.aux(n)`；Command 加 `setAuxSource`。
     - 好处：一处换源、多处跟着变；API 一条命令切 Aux；兼容层现在报 NotImplemented 的 SetOutput2–4 有了对应（Packages/SwitcherControl/Sources/VMixCompat/FunctionCatalog.swift:117、123）。
     - 代价：契约 + reducer + 渲染（每个通道多一次合成和 NV12 转换）+ 各运行表 + 文档，工作量 L。
   - 理由：v1 用户（教会 / 学校）多数是一两块屏 + 录制 + 推流，每个输出自选源已经够用。通道的价值在"好几个输出跟同一路走"，正是后续方案 §3.6 的 Aux 路由。现在加进来，会让 OutputState.source 和 aux 两套来源叠在一起，状态更难懂。
2. **效果链没接进引擎怎么处理**
   - 选项：(a) 先接总线三格（包里现成，S–M），同时给输入加效果槽（M–L）；(b) 接好之前界面标"尚未生效"（R6-M02）。
   - 倾向：(a) 和 (b) 一起做，先 (b)。
   - 理由：设计方案 §1.2 承诺了"每输入 EQ / 压缩"，现在界面能调却不出效果，比没有入口更误导操作员。
3. **EQ 的形态**
   - 倾向：默认用参考那种 10 段图示 EQ（操作员好上手），参数 EQ 放"高级"。
   - 引擎用苹果 AUGraphicEQ / AUNBandEQ，接之前先写探针验证频点和范围。
   - 要提案：给 EffectSlot 加新 id 和键表（docs/CONTRACTS.md:139-147）。
4. **压缩器的形态**
   - 倾向：简单模式只给"阈值 + 比例 + 输出增益"，比例在 App 侧换算成 DynamicsProcessor 的 Headroom，这样不用改键表；起音 / 释放 / Headroom 放高级。
   - 如果换算不准（要探针量），再提案加 `ratio` 键。
5. **噪声门 / 前级增益（trim）/ 自动增益进不进 v1.x**
   - 倾向：噪声门做（麦克风几乎必开，参考默认页之一；要提案加键）；trim 做但放 P2（要提案加 InputAudioSettings 字段）；自动增益不做。
6. **RecordSettings.container 怎么收口**（reports/w1-outputs.md:121 契约疑问 4）
   - 倾向：界面删掉"容器"，只留"文件格式：.mov / .mov 停止后转 .mp4"（R6-M09）；契约里 `container` 按提案改义为"最终文件格式"或标废弃。
   - 直接写分片 MP4 属后续方案 §1.3。
7. **底栏"录制"要不要继续"PGM + ISO 一起起停"**
   - 参考把多路分录放在另一个按钮（图 134，归 MultiCorder 那位）。
   - 倾向：保持一起起停。同拍起步是我们的优势，ISO 是在 ISO 页明确勾选的；按钮已经显示路数。
8. **录制的音频来源 / 音频延迟 / 分段放哪个版本**
   - 倾向：都放 v1 之后。音频来源和分段各需一个契约字段（提案）；音频延迟跟后续方案 §4.3 一起做。
9. **底栏外部显示按钮做不做分体（齿轮弹菜单 + 主体一键开关）**
   - 倾向：做（R6-M16），与界面稿的"齿轮 + External"一致。
   - 主体的语义定为"所有外部显示一起开 / 关（setOutputEnabled），设置保留"。
10. **录制默认值**
    - 倾向：保持 .mov + 片段；"停止后转 MP4"默认关（转封装会临时多占一倍空间，Mac 上的剪辑软件都能直接读 .mov）。
    - 录制的默认视频码率要不要跟节目格式走、音频码率要不要提高：具体数值请用户定（R6-M12）。
