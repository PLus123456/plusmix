# docs/contract-changes/ —— 契约变更提案

SwitcherContracts 在 P1 冻结之后，任何公开类型、JSON 字段名、测试图案布局的改动都不许直接改，先在这里写提案，然后停下来问用户（通用前言铁律 1）。

文件名：`NNN-<主题>.md`，三位递增编号。内容固定：
```
提出会话 / 分支：
改什么：（类型 / 字段 / 布局，前后对比）
为什么：（哪个测试 ID 或哪条设计要求做不到）
影响谁：（哪些包、哪些分支要 rebase）
怎么迁移：（Show 文件 schemaVersion 要不要升、旧数据怎么办）
状态：待批 / 已批 / 驳回
```
用户批了之后由 P1 会话（或新开的契约会话）改 SwitcherContracts，其他分支 rebase。提案文件留着当决策记录。
