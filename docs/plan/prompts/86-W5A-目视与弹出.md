## 86 W5-A 目视与弹出：转场列排版、底栏弹出朝上、主窗口分栏与位置、文案合规与关于面板（第五波 · 止血；用户 2026-09-29 批开）
分支：w5-app-visual（从 main 开）。只准动：App/。
先读：docs/ui-study/03-目视检查.md 全文（两处点名问题的量化、根因、改法与原型截图 img/）；reports/issues/UIA-w3-app-transition-column-misaligned.md、UIA-w3-app-bottom-bar-popups-overflow-window.md、UIA-w3-app-split-view-and-window-state.md、UIA-w3-app-ui-copy-compliance.md、UIA-w3-app-visual-defects-batch.md、UIA-w3-app-misc-logic-bugs.md（第 1、5、6 条）；docs/ui-study/01a-改动总表.md 的 E1、C3（最小步）、C5、C6、A4、P4；02 X61、X62；docs/ui-study/04-待拍板.md Q01（默认：0.1.0 先做 B 的最小一步）；reports/claude-vmix-28-guide-menu-ui-c83cd1.md §5（翻转坐标、alignment 无效、popover 尺寸三条坑）。

背景：用户点名的两处目视问题（转场列"丑、没对齐"、底栏菜单超出边框）在调研的临时拷贝里已有原型并实测通过，正式实现按 03 的改法重写；同批把只动 App、不改契约、不碰直播安全逻辑的目视 / 文案项一起收掉。直播安全（确认、失败路、锁字段）在 87，别在这里做。

交付（每条先写红测试；用例放 App/Tests/，函数名带 ID）：
1. **底栏弹出朝上**（E1；X50 / X63）：抽一个底栏弹出的帮助函数（菜单 `at: NSPoint(x: 0, y: -menu.size.height + 1)`；popover `preferredEdge: .minY`），"外部输出"菜单和"叠加…"弹出层都走它；"显示器 ▸"子菜单拍平成段标题；叠加弹出层 `preferredContentSize = 400 × min(640, 窗口内容高 − 120)`、表单高度可伸缩。用例 `testUI_bottomBarPopupsStayInsideWindow`：1440×900 与 1100×700 两种窗口，底栏每个弹出物的 frame 都在主窗口 frame 内（走窗口坐标 / cacheDisplay，不依赖屏幕录制权限），叠加表单每行标签完整。
2. **转场列排版**（03 §1.3 的布局表逐项）：`stack.alignment = .leading` + 每行 `widthAnchor == stack.width − 16`；两档控件（regular 24 / 13 pt、small 20 / 11 pt）；组内 4、组间 8、组标题到控件 2；T-bar 把手与按钮同宽、最小高 60；时钟 56 高、1 pt `Theme.divider` 边框、`setLocalizedDateFormatFromTemplate("hmma")`；高亮态标题一律白字（FTB / 录制 / 静音的红底，V-05）。用例 `testUI_transitionColumnEdgesAligned`：列内所有可见控件左右边一致；列最小高 ≤ 409，1100×700 时 T-bar 行 ≥ 60。
3. **转场列的最小步**（Q01 默认；C3 / C5 / X16 / X39 / X40）：T-bar 上方那行改成可点的弹出菜单，列五种类型，选 = 只发 `setTransition`（不执行）；时长分段加"自定义…"，时长不是预设时显示"✓ 自定义：0.75 s"；按钮悬停提示从当前快捷键表反查（去掉写死的"回车"）；点 Fade / 菜单 Fade 改了类型时那一行明显变化。用例 `testUI_tbarTypeMenuSelectsWithoutExecuting`（选 Wipe 后快照 `transition.type == .wipe` 且 program / preview 不变）。
4. **主窗口分栏与位置**（X61 / X45 / X47 / X44）：分栏改 NSSplitViewController 或 delegate `shouldAdjustSizeOfSubview` 对输入条 / 调音台返回 false（原型实测 1100×700 时输入条 197、调音台 339）；`center()` 只在没有存档时调；打开节目读回 `Show.layout` 的 mixerPanelVisible / multiviewWindowVisible / mainWindowFrame；输入设置窗 autosave 名带编号。用例 `testUI_splitKeepsInputStripMinimum`、`testShow_layoutKeysRestoredOnOpen`。
5. **文案合规与关于面板**（P4 / X59 / X62 / V-13 / V-14）：偏好设置里兼容层一节的标题去掉模块名（两种语言）；关于面板改 `orderFrontStandardAboutPanel(options:)` 带 credits：版本、Apache-2.0、"NDI® is a registered trademark of Vizrt NDI AB"、"查看开源许可"（打开包内 Licenses/，没有时打开 THIRD_PARTY 说明）；界面文案里 NDI 首次出现写 NDI®；V-14 列的开发术语（测试标准 §2.1、BLOCKED-签名、AVCaptureDevice、ParametricEQ、`--api-listen`、时钟从属、环形缓冲、scheme、bltn 等）改成操作员能懂的话。用例 `testL10n_noModuleNameInUserStrings`（两份 .strings 都不含 VMixCompat）、`testL10n_ndiTrademarkInAboutCredits`。
6. **小逻辑与目视 S3**（UIA-w3-app-misc-logic-bugs 1 / 5 / 6；03 §3 里 ≤ 10 行的）：外部输出菜单的勾按 enabled、点击 = `setOutputEnabled` 开关、删除单独一项；转场列 Overlay 空通道按下用当前 PVW 那一路打开（C6，`overlay(ch, on: true, input: pvw)`）；窗口菜单"调音台 / 多画面"按可见性打 ✓；调音台内容顶对齐（V-03）、PVW 标题条对比度（V-06）、偏好设置数字不加千分位（V-12）、路径为空时占位（V-17）、声像滑块中点刻度（V-27）。每条一个小用例或并进现有用例。
7. `make test-app` 全量 0 失败（空机器；先 `pgrep -fl "xcodebuild .*test"`）；`make lint BRANCH=w5-app-visual`。

不做：录制 / 推流的确认与失败路（87）、效果链标注（87）、底栏三段式 / ⚙ / ▴（92）、转场槽（100）、包与契约。
