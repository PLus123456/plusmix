## 66 W3-B2 合成三期收尾：多画面的纯音频格 / 真实电平表 / 名字标签，删 010 的过渡读取（合成续做）
分支：w3-compositor-3（从 P3 / prompt 61 合入后的 main 开）。只准动：Packages/SwitcherCore/Sources/SwitcherRender/、Packages/SwitcherCore/Tests/SwitcherRenderTests/、Tests/References/。
先读：reports/issues/W2A2-w3-compositor2-multiview-audio-only-cell.md（用户 2026-09-23 定的样子）；reports/p3-contracts.md §4 第 1 条（过渡后备读取该删了）、§5 第 1 / 4 条（两个输出环常驻、格子像素算式的舍入）；
reports/w3-compositor2.md §1（多画面布局表、`drawMeterPlaceholder`、显示层有没有画名字）；docs/CONTRACTS.md §2.4"纯音频输入"、§2.7 `Stats.audio.meters`（提案 004）；测试标准 §3 V8；设计方案 §3.2（渲染线程零分配）。

背景：W2-A2 落地了纯音频设备输入（`InputSource.audio`，没有画面、引擎挑帧恒为 nil），多画面里它的格子现在和"摄像头掉了"一样是黑的。多画面的电平表只画了位置（"真实电平在 Stats.audio.meters 里，第一版这里只画位置"）。
P3 落地 010 后渲染器优先读正式字段，`effects["border"]` / `extra["layout"]` 的后备读取按提案保留一个版本——`Show.load` 已经会把旧键搬进正式字段，后备只对没经过 `Show.load` 的内存状态有意义，该删了。

交付：
1. **纯音频输入的多画面格**：深灰底（不是黑）+ 输入名字 + 电平表；电平表对纯音频输入总是画（它是这一格唯一的内容），不受 `MultiviewLayoutSettings.meters` 开关影响，其它输入仍按开关。
   判断"纯音频"不加契约：`MixerSnapshot.state.inputs` 里 `InputConfig.kind == .audio`；按快照 sequence 变化时算一张"哪些编号是纯音频"的定长表，渲染线程查表（每帧零分配）。
2. **真实电平表**：`Stats.audio.meters.inputs` / `buses` 的峰值与 RMS 以不分配的方式递给渲染器（固定大小的双缓冲表，非实时线程写、渲染线程读；组装方 App / headless 每秒或每次 Stats 发布时 `setMeters`），
   多画面的输入格、PGM / PVW 格画真实电平（峰值保持 1 s，−60…0 dBFS，颜色分段按设计方案 §7 的表；没有数据时退回现在的占位）。
3. **名字标签**：每格左下角画输入名字（PGM / PVW 格画"PGM"/"PVW"）；文字纹理在快照变化时于非渲染线程生成（CoreText → 位图 → 纹理，最多 64 格），渲染线程只贴图；显示层（`MetalDisplayView+Multiview`）若已画名字则统一到渲染器这一处，别画两遍。
4. **删过渡读取**：`OverlayDecoration.resolve` 只读 `OverlayState.border`，`MultiviewLayoutTable.parse` 只读 `OutputSettings.multiview`；对应的 P3 用例（`testP3_borderOfficialFieldMatchesEffectSlotPixelForPixel`、`testP3_officialMultiviewFieldMatchesLegacyExtraKey` 里"过渡键"那一半）改成"只认正式字段、旧键被忽略"，
   不是简单删断言；`Show.load` 的搬迁留在契约里（不是本会话的目录，不动）。
5. **可选**：PVW 输出环按需建（P3 §5 第 1 条：现在无条件建、1080p / ringSize 8 常驻约 25 MB）——只在状态里有需要 PVW 的 enabled 输出或 `options.previewOutput` 时在**状态线程**建，渲染线程仍不分配；做不到就写清楚为什么。

测试（函数名带 ID）：
- `testV8_multiviewAudioOnlyCellPlaceholder`：含一路 `.audio` 输入的 3×3 多画面参考图（Tests/References/ 新增一张，PSNR ∞），电平表位置 / 名字都在，`meters = false` 时该格仍有电平表；
- `testV8_multiviewMetersFromStats`：给定 meters 表（三路不同电平）→ 参考图；没给表 → 与占位图相同；
- `testMultiview_meterTableUpdateDoesNotAllocateOnRenderThread`：`setMeters` 100 次期间渲染线程 0 分配（AllocationProbe）；
- 名字标签：快照换名字后下一帧更新、渲染线程 0 分配；
- 删过渡读取后：带 `extra["layout"]` 但没有 `multiview` 字段的状态渲染成默认布局（不是旧布局），`effects["border"]` 不再画边框；V8 参考图集其余不变（PSNR ∞）。

不做：契约（纯音频判定不加字段；电平口径若要加字段写提案）、App / headless 的 `setMeters` 调用点（各归 W3-E2 / 检查点，报告里写清接口）、Aux 全分辨率（W3-C2）。
报告 reports/w3-compositor-3.md：电平表数据通道的接口与线程约定、名字纹理的生成时机与上限、删过渡读取后哪些用例改了、可选项做没做。
