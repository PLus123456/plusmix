## 132 W2-D5 推流与录制：Adobe 鉴权 AMF 嵌套上限、脱敏的编码参数名与路径发布名、录制首块音频晚到补静音（Codex 10-24 审计 NS04 / NS12 / NS09 + 10-22 审查 N10；G11 2026-10-24 排进 128 前）
分支：`w2-stream-5`（从 G11 快进后的 main 开；与 129–131 / 133 并行）。只准动：`Packages/SwitcherOutputs/Sources/Streaming/`、`Packages/SwitcherOutputs/Tests/StreamingTests/`、`Packages/SwitcherOutputs/Sources/SwitcherOutputs/Recording/Recorder.swift`（只改首块音频锚定那一段）、`Packages/SwitcherOutputs/Tests/SwitcherOutputsTests/`、`App/Sources/Release/ShowRedaction.swift`、`App/Tests/ReleaseTests.swift`。

现象（Codex 在 main 1f9be64 实测；g11 树这几处没变）：
- NS04：带 userinfo 的 RTMP 地址走 `RTMPAdobeAuth.authorize`，`Reader.value()` 对 AMF0 严格数组 / 对象递归无深度限制；本机恶意服务端在 `_result` 第三个值里嵌 10 万层单元素数组（约 500 KB）→ 客户端 SIGBUS（栈保护页），推流进程没了；100 层走到可捕获的拒绝分支。RTMPS 共用解析器。
- NS12：`StreamURLRedaction.redactQuery` 按原始参数名比 `secretQueryParams`，`pa%73s=demo-secret` 不打码，Foundation 解出来却是 pass；诊断包的 show JSON 原样带密码。
- NS09（已知 S2）：密钥栏空、密钥在地址末段（`rtmp://h/live/KEY`，`StreamDestination` 认这种写法）→ 脱敏保留路径，诊断包原样带出。
- N10：Recorder 首块音频 `hostTime > 起点` 时只处理"早于起点裁切"，没补前导静音，首块写到样本 0，下一块才按 drift 补静音——1 s LPCM 实录首块 PTS = t0 + 0.5 s，解码首个非零样本在 0、应在 24000 ± 1，总长 47999 看不出来。

做（先写红用例再改；用例名带 ID `testNS04_…` / `testN10_…`）：
1. **NS04**：`Reader.value(depth:)` 带深度，> `maxNestingDepth`（建议 32；真实 `_result` 不超过 4 层）→ `Failure.protocolError("AMF0 嵌套过深")`；再给总元素数一个预算（建议 10_000）防长时间循环；`reply()` 只经这一个入口。用例：本机回环 RTMP 假服务端（照 C06-server.py 的握手与分块写法，StreamingTests 已有 AdobeAuthGateway / PublishRejectServer 可借）回 100 层 → 协议错误、进程在；10 万层 → 同；正常 `_result` / `_error` / 4 层嵌套照旧过；RTMPS 共用路径靠单元测试（TLS 不另搭）。
2. **NS12**：参数名先 `removingPercentEncoding`（解不开按原文）再小写比名单；非敏感参数原样保留文字。用例：`pass` / `pa%73s` / `%70ass` / `PASS` 都打码；`?user=alice&pa%73s=x` 输出里没有 x。
3. **NS09**：`StreamURLRedaction.redact(url:publishNameInPath:)`（默认 false）：true 且 scheme 是 rtmp / rtmps 且路径 ≥ 2 段 → 末段换成标记（拆法与 `StreamDestination` 一致）；`ShowRedaction.redact(json:)` 处理 stream 字典时看同层 `streamKey` 为空就传 true；日志 / 错误文字那条口径不变（本来不带发布名）。用例：ReleaseTests R7 补"整条地址 + 密钥栏空"一条（zip 里的 show JSON 找不到 KEY），密钥栏非空时路径照旧保留。
4. **N10**：首块 `blockStartNs > originNs` → 先 `appendSilence(frames: round((blockStartNs − originNs) × rate / 1e9))`（受 stop 边界限制，同现有 drift 分支）再锚定；覆盖首块早到（已有）、晚到、整块越过 stop、只有一块四种。Codex `Audit20261022RecorderTests` 搬进 SwitcherOutputsTests 改名 `testN10_lateFirstAudioKeepsTimestamp`（真录 1 s、AVAssetReader / ffmpeg 读首个非零样本 = 24000 ± 1）转绿。
5. **有余力**：reports/issues/W4C4-w2-stream-last-error-raw-texts.md（S3）：`last_error` 里底层库原样文字改中文概括、原文进日志（`连接失败：请求超时` / `发布被拒：<状态码> <描述>` …），改了告诉 W4-C5。
6. Outputs 整包（StreamingTests 的 MediaMTX 用例同机别和别的会话撞端口）、App 的 ReleaseTests；`make lint BRANCH=w2-stream-5`。
