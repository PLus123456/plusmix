## 153 W6-D 输出口出画：外部显示与 NDI 送"输出口 n"、点对点的条件、拔线不影响别的（第六波 · 第二层；P6b 做完后就能开，不等外观评审）
分支：w6-outputs（**叠在 `p6-contracts` 上开**）。只准动：Packages/SwitcherOutputs/。模型：**Opus 5.5，推理档位 max**。
先读：批过的 docs/contract-changes/036（`OutputSource` 的新来源、`RenderedFrame` 里输出口帧的形状、Stats 分项）；docs/spec/大屏与时间线方案.md §3.2、§3.7、§8（V16 / S10 / L6）、§9.3（三处探针）；docs/contract-changes/013、015（外部显示选屏、拔线的口径）、019（输出的 Stats）；Packages/SwitcherOutputs/Sources/External/ 全部（PGM / PVW / 多画面那条路，和输入直出的 `AuxInputPresenter` 那条路：后者的着色器注释写明 1:1 时逐值相同）、Sources/NDISend/、Sources/SwitcherOutputs/Feeding/；reports/claude-large-screen-preview-timeline-af075d.md §5"外部显示有两条路"。

背景：做大屏时，画布是按现场摆法画的，送给 LED 处理器的是"输出口"：一路 1080p 或 4K 信号，里面每块屏放在处理器要截取的位置。渲染器（W6-B）负责把画布打包成输出口的画面，本会话负责把它送出去：外部显示（HDMI / DP，最常见）和 NDI。LED 处理器要的是原值，一个像素都不能被缩放或改色。渲染那边并行在做，本会话对着契约写，用合成帧测，端到端等检查点。

交付（每条先写红测试，函数名带测试 ID；铁律 10：不确定的系统行为先写探针）：
1. **探针：外接显示口能不能逐像素送出**（新加一个可执行目标放在本包里）。要回答三件事：非 HiDPI 模式下 drawable 是不是等于显示模式的像素数；CAMetalLayer 的色彩管理会不会改值；窗口盖满全屏时有没有被系统合成器缩放。做法：把 1 像素棋盘格和灰阶条送到外接口。**用采集卡或 LED 处理器回采逐值比这一步是 BLOCKED-硬件**（用户手里有设备）：写明要什么设备、怎么接、跑哪条命令、看哪个数；没有硬件时先做软件能做的部分（读回 drawable 的尺寸、层的色彩空间设置），并写明这不等于线上的值。
2. **外部显示送"输出口 n"**：选屏、拔线、`Stats.display[]` 沿用 013 / 015 的口径。`testS10_rasterDisplayUnplugged`：一个输出口对应的显示器拔掉，别的输出口、录制、推流不受影响；插回自动恢复。
3. **点对点的条件**：显示器当前分辨率 = 输出口宽高、缩放 1 倍。对不上时在状态 / Stats 里给出"这块屏现在是 A×B，输出口是 C×D，画面会被缩放"所需的字段（App 拿去标黄），字段按 036。
4. **NDI 发送**送"输出口 n"。
5. **探针：多个输出口之间差不差帧**。两路外部显示同时送闪光帧，回采看差几帧、稳不稳定。回采同样是 BLOCKED-硬件，写清解锁条件。
6. **L6**：`testL6_rasterPathLatency`，输入到输出口画面的内部延迟，对比同一路输入到 PGM，差 ≤ 1 拍（合成帧打戳测）。
7. 036 如果批了"只取画布上的一块"给录制 / 推流：做在最后；余量不够就留给续做，报告里写明。
8. `swift test`（SwitcherOutputs 整包 0 红；别和 App 的用例同时跑，apiPort 会撞）；`make lint BRANCH=w6-outputs`，归属检查带 `--base p6-contracts`。

不做：渲染器里的打包（W6-B）；SDI 输出卡与逐帧锁定；App 的菜单和设置页（W6-E2）。
