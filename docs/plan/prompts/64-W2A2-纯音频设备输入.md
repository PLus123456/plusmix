## 64 W2-A2 纯音频设备输入：Core Audio 输入设备 → 音频环（输入续做）
分支：w2-inputs-2（从 G4 合入后的 main 开）。只准动：Packages/SwitcherInputs/Sources/SwitcherInputs/、Packages/SwitcherInputs/Sources/SwitcherInputsHarness/、Packages/SwitcherInputs/Tests/SwitcherInputsTests/、Tests/Fixtures/（不动 DeckLink / NDI）。
先读：docs/CONTRACTS.md §2.3（音频环 `AudioRing`）、§2.4（`InputSource.audio(deviceUID:)`、`InputStatus` 的 noSignal / error 口径——W3-A 报告 §4 第 4 条，用户 2026-09-22 定，P3 写进注释）；
reports/w2-inputs.md §1（CameraInput 的音频那一半、HotplugTimer、CameraPermission 的做法）；设计方案 §3.5 / §3.6；测试标准 §2.3、A1 / A2；reports/G4.md §7 最后一行、§8 第 8 条。

背景：契约里 `InputSource.audio(deviceUID:)` / `InputKind.audio` 从 P1 就有，W3-E 的 Add Input 也有"纯音频设备"页，但没有任何运行实现：App `InputFactory` 的 `.audio` 分支抛 unsupported。
典型用途：USB 声卡 / 小调音台上的主持人话筒、没有视频的音频源。用户 2026-09-22 把它定给本会话（G4 报告 §8 第 8 条）；App 接线归 W3-E2（prompt 63 第 7 条）。

交付：
1. `AudioDeviceInput`（`Sources/SwitcherInputs/Audio/`）：用 AudioUnit（kAudioUnitSubType_HALOutput 的输入侧）或 AVAudioEngine 从指定 deviceUID 取样，**回调内无锁、无分配、无日志、无系统调用**（设计方案 §3.5）：
   回调里只做 hostTime 打戳 + 写 `AudioRing`。设备采样率 ≠ 48 kHz 时不要在回调里转换：优先把设备固定到 48 kHz（失败 = noSignal + 文案"设备不支持 48 kHz"），或在专用线程用 AudioConverter 转再写环——报告里写清选了哪种、为什么。
   声道数由组装方定（现在 App / headless 的环都是 2）；多声道设备默认取前两路，`Options.channelMap` 可选两路（不进契约，包内选项）。
   没有视频：帧槽不推帧，`InputState.status` 只由音频决定——有块 = live；设备不在 / 被拔 = noSignal + lastError 文案（会自己好，热插拔用 W2-A 的 HotplugTimer 那套）；麦克风权限被拒 = error（不会自己好）。
2. `AudioInputDevices.list()`（uid、名字、声道数、采样率、是否系统默认输入），给 Add Input 表单与 harness 用；设备增删通知刷新列表。
3. 时间戳：每块 hostTime 用回调给的 `AudioTimeStamp.mHostTime`（设备侧采样时刻）换算成 host time 打戳（铁律 5），不用回调到达时刻；A2 用整秒 click 与 PGM 的闪光对得上。
4. `switcher-input-probe` / SwitcherInputsHarness 加 `audio-device` 子命令：列设备；指定 uid 跑 N 秒，报块数、断裂、hostTime 单调性、块间隔分布。

测试（函数名带 ID；没有输入设备时 XCTSkip 写 BLOCKED-硬件，内置麦克风算设备）：
- `testA1_audioDeviceInputNoDiscontinuityFor60s`：60 s 环里块连续、hostTime 单调、块间隔 = 块长 ± 1 ms、underrun 0；
- `testA2_audioDeviceBlockHostTimeIsDeviceTimestamp`：块上打的是 mHostTime，与回调到达时刻的差稳定（标准差 < 1 ms）；
- `testS4_audioDeviceUnplugGoesNoSignalThenRecovers`：BLOCKED-硬件，写清人工步骤（拔 USB 声卡 → noSignal + 文案 → 插回 → live，不用重建输入）；
- `testRT_audioDeviceCallbackAllocatesNothing`：W1-B 的 AllocationProbe 按线程计 malloc = 0（回调线程，10 s）；
- 权限：`testPermission_microphoneDeniedIsError`（TCC 拒绝时 status = error；从 Terminal.app 跑，BLOCKED-权限 时 skip）。

不做：App 接线（63）、契约改动（输入声道映射若确实需要，写提案 014，不自己加字段）、DeckLink / NDI。
