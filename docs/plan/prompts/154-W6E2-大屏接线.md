## 154 W6-E2 大屏接线：把定稿的外观接上引擎（按输入切、点分区放输入、调预设、直出、对位图、屏幕编排生效）（第六波 · 第二层；检查点 2 里用户认可外观之后开）
分支：w6-app-stage（**叠在 `g17` 上开**：集成分支里有契约、渲染、状态机、工装和定稿的外观）。只准动：App/，外加 reports/w6-app-stage/（截图）。模型：**Opus 5.5，推理档位 max**。
先读：reports/G17.md（用户对外观的裁定、集成分支上还红着什么）；reports/w6-app-stage-look.md §4 / §5；批过的 036 / 037；docs/spec/大屏与时间线方案.md §3.4（十条规则与用户场景表）、§3.7、§3.8、§5；reports/w6-engine.md、w6-render.md 的 §5；App 里 W6-E1 留下的草稿模型与假数据入口。

背景：外观用户看过、定稿了。本会话把它接上真的引擎：界面上每个动作只发命令，显示只读快照（和现有界面同一条规矩）。假数据入口全部拆掉。

交付（每条先写红测试，函数名带 `testW6E2_`）：
1. **屏幕编排窗生效**：草稿 →"应用"发 `setStage`，"取消"丢掉；改了屏幕（画布尺寸变了）走换节目格式的流程，并提示"这会重建画面，开演前做"；改布局、分区、上屏位置不重建。节目文件存取舞台（存、另存、打开、老文件照开）。
2. **上屏位置**：标签读状态；右键菜单与拖到分区发 `setInputHome`；"按形状分配"确认后一次发完。
3. **导播面板的切换**：点格子 = `setPreview`（预监里它进自己的上屏位置）；⇧ 点 = 直切；⌘ 点 = `setZonePreview` 叠加到现有预监上；转场列的 Cut、转场槽、T-bar、FTB 不用改（状态机已经按墙面状态做）。
4. **大屏面板**：点分区再点输入 = 把这一路放进这一格的预监；布局切换；监看里分区的边线、名字、选中、双击放大，叠在真的 PVW / PGM 上（显示路径不多一次拷贝）。
5. **画面预设**：预设条与预设表读写 037 的预设；"存当前预监"；调预设（界面与 F1…F10）。
6. **直出**开关、**对位图**按钮接上；直出开着时界面上要一眼看得出（按 G17 里用户定的样子）。
7. **红绿灯与标签**：在屏上的是红，在预监里的是绿，按快照里的 Tally。
8. **输出**：外部显示菜单与输出设置页能选"输出口 n"；点对点对不上时设置页和底栏标黄并写明原因（字段来自 W6-D，合进来之前用契约字段造值测）。
9. **用户场景表端到端**（方案 §3.4）：`testW6E2_userScenarioEndToEnd`，从界面点到快照到监看视图，五行逐行断言。
10. 没配大屏时：导播面板和 W6-A 做完时逐项相同（现有用例不改口径），大屏面板是引导页。
11. **检查点 3 的截图**（真画面）：reports/w6-app-stage/shots/：用户场景的五步各一张（1440×900）；两个面板；编排窗三个页签带真数据；预设表；直出开着；对位图；输出设置页的点对点告警。
