现象（132 本机实测，macOS 27 / HaishinKit 2.2.5）：只 `listen` 不 `accept` 也不回字节的端口（内核替它完成三次握手）→ `rtmp://127.0.0.1:<端口>/live/k`、连接超时 3 s：state 一直 `connecting(1)`、last_error 空；后台线程 `stop()` 20 s 不返回、state 停在 `stopping`；传输层 `withTimeout(seconds: 4) { connect() }` 25 s 没返回；`rtmps://` 要 15 s（TLS 超时）才回。没人听 / 域名解析不了 / SRT 没人听都正常。原因：HaishinKit `RTMPConnection.connect` 的握手与 connect 命令没有超时、不理取消；我们的 `withTimeout` 任务组要等不理取消的子任务；`stop()` 等发送 Task 结束。App 里：这一路永远"连接中"、点停停在 stopping、`streams[n]` 不清、再也起不来；换节目 / 退出等满 10 s 兜底并泄漏连接。

做（先写红用例再改；用例名带 ID `testW2D6_…`）：
