背景：用户要求每个检查点把真机外观拿给他看，他有想法再改，所以界面先做外观、后接线。本会话把大屏这一层的界面用假数据搭出来：能点、能拖、能看，但不向引擎发任何大屏的命令。监看里的画面先用占位图（按假数据画的分区色块）。用户认可外观之后，接线归 W6-E2（prompt 154）。

交付（视图层的用例先写；函数名带 `testW6E_`）：
1. **两个面板**：工具条正中"导播 ｜ 大屏"分段开关（快捷键先按 ⌘1 / ⌘2，和现有菜单不撞才用）。切面板不换监看、转场列、输入、调音台、底栏，只多出三样：布局与编排的工具行、画面预设条、时间线条（时间线条本会话只留一条占位，内容归 W6-G1）。用例：切面板前后 PVW / PGM 是同一个视图对象。
2. **监看里的分区**：边线和名字（可开关）；大屏面板里点一格 = 选中；双击一格 = 只放大看这一格，再双击回来。假数据用内置的示例舞台：2460×1080，布局"整屏"和"中间 + 两耳"（方案 §3.9 的数）。
3. **上屏位置**：输入格子上的小标签（"→ 中间"）；右键"上屏位置 ▸"按布局分组列出分区；大屏面板里把格子拖到监看的某一格上也能改。
4. **布局与编排工具行**：布局切换、"屏幕编排…"、"预设表"、"对位图"。转场列加"直出"开关（外观）。
5. **画面预设条**：一格一个预设（名字 + 一张按布局画的小图）、"＋ 存当前预监"；**预设表**窗口：行 = 分区（按布局分组），列 = 预设，格子里是输入名，能把输入拖进格子。
6. **屏幕编排窗**（独立窗口，三个页签）：
   - "屏幕"：拖到现场的相对位置，吸附对齐，X / Y / 宽 / 高直接填像素。
   - "布局"：左边布局列表，右边在舞台上画分区；把一块屏切开、把几块屏并成一格；标星的默认分区；下面列出每路输入的上屏位置，带"按形状分配"的确认表。模板：整屏、中间 16:9 + 两耳、左右对半、三等分、每屏一格、底 + 小窗。`testW6E_templateCenterWithEars`：2460×1080 套"中间 16:9 + 两耳"得到 1920×1080（从 x = 270 起）和两条 270×1080。
   - "输出口"：建 1920×1080 / 3840×2160 / 自定义的输出口，把屏幕的矩形拖到信号里的位置，默认和现场摆法一样，"自动排布"，越界和重叠标红。
   - 编排数据放在窗口自己的草稿里，本会话不发命令。
7. 没配大屏时大屏面板的**引导页**（先画屏幕 → 定布局 → 给输入定上屏位置）。
8. 文案中英两份；用词按方案 §3.1，不出现别家软件的名字。
9. **检查点 2 的截图**：扩展截图脚本，出图到 reports/w6-app-stage-look/shots/：两个面板各两种窗口（1440×900、1728×1117）；编排窗三个页签；预设表；引导页；监看放大一格；上屏位置的右键菜单。测试卡的形状跟着画布走（W6-A 补拍时的做法）。
