背景：时间线面板的外观用户看过、定稿了。本会话把它接上引擎：界面只发命令，显示只读快照。假数据入口全部拆掉。做完之后，用户能用一份分好段的 PPT 加他那面墙，从开场走到结束。

交付（每条先写红测试，函数名带 `testW6G2_`）：
1. **走带条**：GO、上一条、暂停、跳到某条 / 某段、选时间线、"回到时间线"接上命令；"第几段 · 第几条"、下一条的名字读状态。
2. **预监里是下一步**：走到某条时，PVW 显示下一条的画面（状态机已经装好，界面只显示）；人手动改了之后界面上看得出"已离开时间线"。
3. **编辑**：时间轴视图与列表视图里对提示点的增、删、改、拖动排序、分段，落成"整体替换一条时间线"的命令；节目文件存取时间线。
4. **幻灯片列表**：添加输入的新类型（文件夹 / 多选图片 / PDF）；格子上的上一张、下一张、"第 n / 共 m 张"；设置页的缩略图、排序、分段。
5. **按幻灯片生成提示点**：选一路幻灯片列表，一张一个提示点、段落照搬，生成前给预览，确认后落进时间线。
6. **录下操作**：开关接上状态机的记录；停下后把记下的草稿落成提示点，可以再改触发方式。
7. **快捷键**：→ / PgDn = GO，← / PgUp = 上一条（按 039；光标在文本框里时让位）；"大屏面板里数字键调预设、空格 = GO"的开关；翻页笔发 PgUp / PgDn 能走时间线（用例用键事件模拟）。
8. **整场走一遍的用例**：`testW6G2_annualMeetingEndToEnd`，装"年会流程"时间线和一路 24 页的幻灯片列表，从界面按 GO 走完，每一步断言 PGM / PVW 的墙面状态与幻灯片页号。
9. 没配时间线时：两个面板和检查点 3 之后逐项相同。
10. **检查点 5 的截图**（真画面）：reports/w6-app-timeline/shots/：整场五步各一张；时间轴视图与列表视图；编辑提示点；幻灯片设置页；生成提示点的预览；录制操作开着。
