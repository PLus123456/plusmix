先读：批过的 docs/contract-changes/038（走带在 `advance` 里的规则那一节逐句读）、039（默认键）、037（提示点引用的画面预设）；docs/spec/大屏与时间线方案.md §4.1、§4.2、§4.3、§4.5、§8（V18 / C10）；SwitcherEngine/State/MixerReducer.swift 的 `advance` 与 `reduce`、StateMachine.swift（每拍先 advance 再 reduce、命令回执、转场事件）；reports/w6-engine.md §5；SwitcherControl 的命令目录、API、Hotkeys、MIDI；Stream Deck 动作在哪加（看 reports/w5-transition-slots.md §5）。

背景：时间线不另起一套出画机制。走到提示点 n 时，PGM 是提示点 n 的画面，预监自动装好提示点 n + 1；按 GO = 这一拍切换，再装下一条。走带放在 `advance` 里，所以时刻逐拍确定，不靠界面线程，无界面也能跑。人随时可以手动切，时间线停在原地，按"回到时间线"再接上。

交付（每条先写红测试，函数名带 ID；`advance` 仍是纯函数）：
1. **走带**：选时间线、GO、上一条、跳到某条 / 某段、暂停；走到某条时把下一条装进预监（调预设 + 再改的分区 + 转场）。
2. **三种触发**：手动；跟随（上一条走完 n 拍后；上一条里某路片子放完时，判据按 038）；定时（距起点多少拍）。
3. **顺带的命令**：按相对拍偏移在对应的拍上应用；同一拍多条的顺序、和外来命令的先后、回执与命令日志里的标记，全部按 038。
4. **手动插手**：人改了预监或直接切了，时间线不被锁住；离开 / 回到时间线的状态与行为按 038。
5. **V18**：`testV18_manualGoLandsWithinOneTick`（GO 到生效 ≤ 1 拍）、`testV18_timedAndFollowCuesExact`（定时、跟随触发相对应到的拍误差 0）、`testV18_oneHourNoDrift`（模拟拍连跑一小时的量，累计误差 0）。
6. **录下操作**：开着的时候，把手动的每一步（点输入、调预设、切换及其时刻）记成提示点草稿（数据层；界面归 W6-G2）。
7. **控制层**：校验器、命令目录（GO、上一条、暂停、跳段）、HTTP / WS API 的状态与命令，`switcher-apidoc` 重生成 docs/api.md；默认快捷键按 039（→ / PgDn = GO，← / PgUp = 上一条；用例断言不撞、文本框里让位）；MIDI 动作；Stream Deck 动作（GO、上一条）。**C10**：`testC10_goViaApiHotkeyMidi`，三条路的 GO 到生效同 C1 的口径。
8. **无界面能跑**：`ScenarioRunner` 与 switcher-headless 能装一条时间线并走完；scenarios/timeline-annual-meeting.json（开场片 → 主持人上场 → 讲 PPT → 互动 → 结束，墙用 20.5:9 那面）。
9. 不配时间线时逐字节不变：沿用 W6-C 的金样口径加一条。
