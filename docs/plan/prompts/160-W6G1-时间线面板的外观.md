交付（视图层的用例先写；函数名带 `testW6G_`）：
1. **走带条**（大屏面板底栏上面，可收起；导播面板里也能打开）：GO、上一条、暂停、"第 2 段 · 提示点 3 / 12"、下一条的名字、"回到时间线"。
2. **时间轴视图**：行 = 分区（每个分区在每个提示点之后放什么，一段一段的色块带输入名）外加一行"命令"；列 = 提示点；分段是一条色带，能折叠、能点段名跳过去；手动提示点是一道停止线；现在这一条和下一条有明显的标记。
3. **列表视图**：一行一个提示点（编号、名字、触发、转场、备注），段标题是一行；和时间轴视图是同一份数据的两种看法。

5. **幻灯片列表**：输入格子上多两颗按钮（上一张、下一张）和"第 7 / 24 张"；"添加输入"里多一种类型（选文件夹 / 多选图片 / 选一份 PDF）；输入设置页：整串页的缩略图、拖动排序、分段、当前页。
