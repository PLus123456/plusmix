## 硬件 / 环境限制（不是缺陷，但用户会撞到）

- 虚拟摄像头需要 App 放在 /Applications 并在系统设置里允许扩展（macOS 的系统扩展规则）。
- 屏幕录制没有 usage key，第一次用屏幕输入要在"系统设置 → 隐私与安全性 → 屏幕与系统音频录制"里手动授权。
- 最低系统 macOS 15；只提供 Apple Silicon 构建。
