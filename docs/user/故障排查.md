# 故障排查

先看两处：输入格子上的一行文案（每路输入自己的状态，[输入 › 输入的状态](输入.md#输入的状态)）和底栏状态行的提示（输出与系统级的事）。
两处都写明了原因和下一步；这一页按症状把它们汇总起来。

## 1. 权限

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 摄像头格子："摄像头权限被拒。打开 系统设置 › 隐私与安全性 › 摄像头，允许本程序后会自动恢复，不用重启" | 第一次弹窗时点了"不允许"，或从来没弹过 | 去那个页面把 PlusMix 打开；≤ 2 s 自动恢复 |
| 摄像头有画面、没声音；纯音频设备格子写"麦克风权限" | 设备自带麦克风 / 音频输入要单独的麦克风权限 | 系统设置 › 隐私与安全性 › 麦克风 |
| 屏幕输入一直"无信号"或写"屏幕录制权限被拒"，而且**从没弹过窗** | 屏幕录制没有系统弹窗，是设计如此 | 系统设置 › 隐私与安全性 › 屏幕与系统音频录制，点 + 把 PlusMix.app 加上，允许后自动恢复 |
| 授权过了，重新编译 / 更新之后又问 | 没有 Team ID 的 ad-hoc 签名每次构建签名都变，系统当成新程序 | `DEVELOPMENT_TEAM=<TeamID> make gen` 用固定身份签名；或者每次重新授权 |
| 权限被"系统策略限制（家长控制 / MDM）" | 设备管理策略禁了 | 找管理员，程序自己解不开 |
| 从终端 / 脚本起的 PlusMix 拿不到摄像头 | TCC 授权归启动它的进程（Terminal、IDE）所有 | 授权给 Terminal.app，或从 Finder / Dock 起 App |

## 2. 无信号

| 输入 | 格子上的文案 | 意思 |
|---|---|---|
| 摄像头 / 采集卡 | "设备已断开，等待重新连接" | 拔了；插回同一个设备自动恢复（≤ 3 s） |
| DeckLink | "没有找到 DeckLink 驱动：安装 Blackmagic Desktop Video（/Library/Frameworks/DeckLinkAPI.framework）后重试，不用重启本程序" | 驱动没装，装好自动好 |
| DeckLink | "无信号" / 列出已连接的设备 | 线没插 / 卡不在；信号回来或卡插回自动好 |
| DeckLink | "DeckLink SDK 未编译进来" | 这是 error：编译 PlusMix 的机器上没有 SDK，要重新编译 |
| NDI | "网络上找不到 NDI 源 …（发送端没开、不在同一网段，或名字不对）" | 等源上线；名字要与发送端显示的 `机器名 (源名)` 一致，添加面板"重新找"能列出当前网络上的源 |
| NDI | "找不了 NDI 源：…" | error：SDK 不在；装 NDI SDK for Apple 到 `/Library/NDI SDK for Apple` 后重新编译 |
| 视频文件 / 图片 | "图片不存在：…" / 文件打不开 | 路径错；相对路径相对节目文件所在目录（[示例 › 相对路径](../../Samples/README.md#2-相对路径)） |
| 纯音频设备 | "已断开，等待重新连接" | 插回自动好；"跟随系统默认输入"的路在系统换默认设备时自动重建 |
| 任何输入 | 画面有、但 60 fps 节目里看着像 30 fps | 摄像头协商到了 30 fps（它不支持 60）：这是设计内的重复，不是丢帧 |

## 3. 磁盘

| 状态行 | 行为 |
|---|---|
| "录制 n：磁盘剩余 x MB" | 低于 1 GB 的提醒，还在录 |
| "录制 n：磁盘剩余 x MB，低于下限 200 MB" | 只停这一路录制；推流、画面不受影响。改下限：启动参数 `--record-min-free-mb` 或 `defaults write` 键 `recordMinimumFreeMB`（0.1.0 的偏好设置里没有这一项） |
| "录制 n：磁盘满（…）" / "已切到备用目录：…" | 写满：保留已写片段；设了备用目录（`--record-fallback`）就切过去继续录 |
| "录制 n 起不来：…" | 目录不可写 / 不存在，或 ISO 那一路的分支用完（每路最多 4 个） |
| "录制 n 封口失败：…" | 停止时写索引失败；`.mov` 带片段，已写的部分仍可播 |

录到外置盘 / 镜像时"剩余空间"按那个卷算（0.1.0 里修过一次非启动卷读成 0 的问题）。进程被强杀：`.mov` 恢复到最后一个 1 s 片段（E6 要求损失 ≤ 2 s）。

## 4. 推流

| 状态行 / API state | 意思 |
|---|---|
| "推流 · 重连中（第 n 次）" / `backoff` | 断线，指数退避重连（上限 30 s）；恢复后自动接上，第一帧关键帧 |
| "推流 n 起不来：…" / `failed` | 地址协议不认识（只认 rtmp / rtmps / srt）、服务器拒绝、密钥错 |
| "推流 n 没有地址" | 输出设置里地址为空 |
| 帧数在涨、播放端却没画面 | 看 `stats.encoder[].dropped`（网络丢帧）：带宽不够时先丢非关键帧；降码率 |
| 本机 MediaMTX 收不到 SRT | MediaMTX 的 SRT 端口要绑 IPv4（`srtAddress: 0.0.0.0:8890`，仓库里的 `scripts/mediamtx.yml` 已改）；RTMP 不受影响 |

## 5. NDI 发送 / DeckLink / 虚拟摄像头没装好

| 症状 | 意思 |
|---|---|
| NDI 页状态"不可用（没有 NDI SDK / 初始化失败）"、`state = unavailable` | 编译时没探测到 NDI SDK：输出不会真的发出去。装 SDK 后 `make clean && make build`（Xcode 会缓存清单里的探测结果） |
| `state = failed`，状态行有原因 | SDK 在但初始化 / 建实例失败：看原因（多半是别的程序占着 NDI 运行时或名字冲突），改设置后重试 |
| 虚拟摄像头："签名 / 权限 / 位置不满足，要带 Team ID 签名、从 /Applications 运行（BLOCKED-签名）" | 开发构建激活不了系统扩展：按 [输出 › 虚拟摄像头](输出.md#5-虚拟摄像头) 的三步 |
| 虚拟摄像头："等待在「系统设置 → 隐私与安全性」里允许" | 系统弹了允许提示但还没点；macOS 15 起在 通用 › 登录项与扩展 |
| 虚拟摄像头："找不到虚拟摄像头设备（扩展未安装 / 未激活）；已丢 n 帧" | 输出开着、扩展没连上；每秒重试，激活后自动接上 |
| 系统设置里看不到扩展 / 激活后 FaceTime 里没有 "Switcher" 摄像头（0.1.0 里虚拟摄像头的设备名仍是代码名 Switcher） | 扩展必须嵌在 /Applications 里的 App 内；换过 bundle id / Team ID 要先"卸载扩展"再装 |

## 6. 画面与声音

| 症状 | 看什么 |
|---|---|
| 状态行"丢帧"（missed_render）在涨 | 渲染没赶上拍点。常见原因：别的程序占满 GPU、机器降频、多画面窗口被盖住时系统降低了刷新。空机器上正常是 0；长跑时用 `caffeinate -u -i -d -s` 防止睡眠（只 `-i` 不够：用户"空闲"时 macOS 会把实时线程的唤醒拖慢 10–18 ms；App 自己还不会阻止睡眠 / App Nap，prompt 98 加） |
| A/V 对不上 | 输入设置 › 音频 › 延迟补偿（0–500 ms）修采集设备自己的偏差；引擎内部的对齐延迟（默认 2048 帧 = 42.7 ms）在偏好设置 › 节目音频 |
| 切走了声音还在 / 切上了没声音 | 看那一路的"跟随视频"：关着 = 一直出声；开着 = 只在 PGM 上出声。总开关在调音台 |
| 耳机里听到的比画面早 | 监听点默认在对齐延迟线之前（低延迟）；要与画面对齐选"延迟线后" |
| 音频设备起不来："音频设备「…」建不起来（…），退到空设备" | 设备被拔 / 被别的程序独占：偏好设置 › 音频输出重新选；空设备下画面照常、录制 / 推流照常有声音（只是本机不出声） |

## 7. API 与控制面板

| 症状 | 意思 |
|---|---|
| "API 起不来（127.0.0.1:8765）：…" | 端口被占（上一个 PlusMix / headless 没退干净）：`lsof -i :8765` 看是谁；偏好设置里换端口 |
| curl 返回 401 | 偏好设置里设了 token：请求带 `Authorization: Bearer <token>`（WebSocket 也可用 `?token=`） |
| 命令返回 200 但 `applied = false` | 状态机按规则忽略了（转场进行中、已是目标状态），不是错误 |
| 返回 400 | 命令结构错 / 引用不存在的输入 / 输出编号；正文里有原因 |
| Stream Deck 按钮灰色"未连接" | API 没开、地址端口不对、token 不对；插件日志在 `~/Library/Logs/ElgatoStreamDeck/` |

## 8. 日志与诊断

- 状态行的提示同时写进系统日志。看最近 10 分钟：

```bash
log show --predicate 'process == "PlusMix"' --last 10m --style compact
```

- 每秒一行的统计（`stats.jsonl`，字段见 [测试标准 §7](../testing/测试标准.md#71-统计字段-statsjsonl)）：启动参数 `--stats <文件>`，或从 API `GET /api/v1/state` 的 `stats` 读。报问题时附上它。
- 复现问题用无界面引擎更省事：`switcher-headless run --show <节目> --duration 60 --stats /tmp/stats.jsonl`（[示例](../../Samples/README.md#1-打开)）。
