# 设置

所有设置在一个"设置"窗里。打开它的入口都通到同一个窗：

- ⌘, 、菜单 PlusMix › 设置…、工具条"设置"主体：回到上次看的那一页（第一次是"常规"）。
- 工具条"设置▾"、菜单 PlusMix › 所有设置页 ▸：直达某一页；PlusMix › 快捷键… / MIDI 映射… 直达那两页。
- 菜单"输出"下面的各设置页、底栏各个 ⚙（录制、推流、外部显示、多画面）：直达对应的输出页。

## 两组页

左侧栏分两组，页头写着这一页存在哪：

| 组 | 存在哪 | 页 |
|---|---|---|
| **本节目** | 随节目文件保存：另存、换节目时跟着节目走 | 节目格式、输出总览、录制、ISO 分路、推流、外部显示、NDI® 发送、虚拟摄像头、多画面布局、节目音频 |
| **本机** | 存在这台 Mac 上，所有节目共用 | 常规、音频设备、远程控制、Tally、快捷键、MIDI、性能与电源、更新与诊断、高级 |

## 改了什么时候生效

- **大多数项改了立刻生效**：输出各页的改动当场发给引擎（在推的推流目的地会锁住地址和编码，见 [输出 › 推流](输出.md#2-推流)）；本机的项改了当场写进本机设置。
- **要换引擎才用得上的项**（节目格式、节目音频、音频设备、本地 API、兼容层、PVW 预览全部叠加）旁边标着"需重起引擎"。改了先记成**待应用**，窗口底部写"有 n 项待应用：…"；
  点底部的"应用并重起引擎"一次用上（录制 / 推流在跑时先问"会停止 n 路录制、m 路推流"，取消 = 不换）。改回原来的值就不算待应用。
  换完引擎设置窗不关，停在原来那一页。不点也没关系：下次起引擎（新建、打开节目、重开 App）时自动用上。
- **快捷键、MIDI 两页要点"保存"**：表要整张检查过（冲突、认不出的键）才能存。有没存的改动时关窗或切到别的页，先问"保存 / 取消 / 放弃改动"；存不了（有冲突）就不关、不切，错误写在表下面。

窗口底部左边三个按钮：

| 按钮 | 做什么 |
|---|---|
| 导出设置… | 把本机设置、快捷键表、MIDI 映射写成一个 JSON 文件（`PlusMix 设置.json`），换机器时带走。**访问令牌（token）不导出** |
| 导入设置… | 选一个导出的文件，先列出"会覆盖这台 Mac 上的：本机设置 n 项、快捷键表（m 条）、MIDI 映射（k 条）"再问；节目不动，要换引擎的项记成待应用 |
| 恢复默认 | 本机设置、快捷键表、MIDI 映射都回到默认，访问令牌清掉（先问）；节目不动，不换引擎 |

## 本节目

| 页 | 内容 |
|---|---|
| 节目格式 | 分辨率（预设 1920×1080、1280×720、2560×1440、3840×2160；"自定义…"填宽 × 高，按偶数取，320×240 … 7680×4320）、帧率（24 / 25 / 29.97 / 30 / 50 / 59.94 / 60）。需重起引擎 |
| 输出总览、录制、ISO 分路、推流、外部显示、NDI® 发送、虚拟摄像头、多画面布局 | 见 [输出](输出.md) |
| 节目音频 | 对齐延迟（节目音频相对采集晚多少，默认 2048 帧 = 42.7 ms；低延迟监听调小，大块生产者调大）、耳机监听点（延迟线前 = 低延迟，默认；延迟线后 = 与节目画面对齐）。需重起引擎 |

## 本机

### 常规

| 一节 | 内容 |
|---|---|
| 提醒 | 录制和推流都没开时提醒（引擎跑了 n 分钟还没开，默认关、n = 5）；FTB 开着满 10 秒时提醒；Master 电平持续 30 秒低于 −50 dBFS 时提醒。立刻生效。提醒出现在主窗口最底一行的右侧（琥珀色），见 [概念 › 提醒、统计窗、界面锁](概念.md#提醒统计窗界面锁) |
| 操作确认 | "停止录制 / 推流前先确认（底栏按钮）"，默认开。只管停止（开始不问）；快捷键、MIDI、API 一律不问；新建 / 打开 / 换格式 / 退出时录制推流还在跑也会先问，那几问不能关 |
| 语言 | 界面语言：跟随系统 / 简体中文 / English。重新打开 PlusMix 后生效 |
| PVW 预览 | "PVW 预览全部叠加"：PVW 画每一路显示中的叠加（与叠加设置窗里每通道的"PVW 预览"取或）。需重起引擎 |
| 外部显示 | "外部显示在主屏上不盖住主界面"：开在主屏（带菜单栏的那块）上的外部显示窗口垫在主界面下面，点它也不翻上来；外接屏上照常全屏在最前。立刻生效 |

### 音频设备

- **设备**：系统默认（跟随变更）/ 空设备（不出声）/ 列出的输出设备。空设备下画面照常，录制 / 推流照常有声音，只是本机不出声。
- **每条总线送到哪两个声道**：Master、Bus A、Bus B、耳机各选一对声道（1/2、3/4……）或"不输出"。两条总线不共用一对声道：选了别的总线正在用的那一对，原来那条改成"不输出"并写一句。
  换设备时只去掉这台设备没有的声道对；"恢复设备默认"回到设备的默认分配。录制 / 推流 / NDI® 用的是 Master 本身，不受这里影响。
- **2 声道设备**（内置扬声器、普通 USB 耳机）：两个声道都给了 Master，页上和调音台头部写"当前设备没有耳机声道"——独听 / PFL / AFL 在耳机总线上，这时听不到。
  "监听时临时占用 Master 声道"这一项这一版还**没有生效**（选上先记下，音频引擎支持后才起作用）；现在要听耳机总线，请换一台多声道设备。
- 改了设备或声道要"应用并重起引擎"。

### 远程控制

两节：**本地 API**（HTTP / WebSocket，[docs/api](../api/README.md)）和**第三方 API 兼容层**（让现成的控制面板配置能用，默认关；法律提示和覆盖表从 [本地 API 文档](../api/README.md) 的目录进）。

| 项 | 本地 API | 兼容层 |
|---|---|---|
| 开关 | "启用 HTTP / WebSocket API"（默认开） | "启用兼容层（默认关）" |
| 谁能连 | 仅本机（127.0.0.1）/ 允许局域网（0.0.0.0） | 同左 |
| 端口 | 默认 8765 | TCP 端口默认 8099、HTTP 端口默认 8088 |
| 鉴权 | Token（留空 = 不鉴权） | 没有鉴权（协议本身没有） |
| 连这个地址 | 只读显示别的机器该连的地址（`http://<本机局域网 IP>:8765`）带"复制"；多块网卡时列出其余地址；找不到局域网地址时写明 | HTTP 地址（`…/api`）、TCP 地址，带"复制" |

允许局域网又没设 token、或兼容层允许局域网时，页上黄字提醒：同一网络里谁都能切画面、停录制。改了要"应用并重起引擎"。
页底"改监听地址…（高级）"跳到[高级](#高级)页，那里可以填具体的 host:port。
**第一次让 PlusMix 监听局域网**（允许局域网、或打开 tally 流）时，macOS 防火墙开着会弹"允许传入连接"，要点允许。

### Tally

"提供只读 tally 流"（默认关）：给局域网上的 tally 灯 / 提词屏用，每次 PGM / PVW 变化推一帧，客户端发什么都不当命令。

- 端口：没单独设 = 本地 API 端口 + 1（8766）。打开就在局域网上监听（0.0.0.0）。
- 页上两行只读地址：WebSocket `ws://<本机局域网 IP>:8766/tally`、HTTP 轮询 `http://<本机局域网 IP>:8766/tally`，带"复制"；下面是当前连接数。
- 开关和端口立刻生效，不用重起引擎；起不来（端口被占）时状态行提示。协议见 [docs/integrations/tally.md](../integrations/tally.md)。

### 快捷键、MIDI

见 [快捷键](快捷键.md)。

### 性能与电源

- "引擎运行时阻止系统睡眠与 App Nap"、"引擎运行时阻止显示器休眠"：默认都开，立刻生效。引擎在跑时 PlusMix 自己拿这两条电源断言，停引擎（退出、换节目的间隙）就放掉；页上一行写着现在是什么状态。
  它挡不住合盖和手动锁屏：**无人值守、要合盖或锁屏的长跑**仍然建议另外跑 `caffeinate -u -i -d -s`（见 [故障排查 › 画面与声音](故障排查.md#6-画面与声音)）。
- 这台机器的只读信息：机型、芯片、内存、GPU、系统。

### 更新与诊断

- 更新：签名并公证的正式发布版每天检查一次（"自动检查更新"可关）、"检查更新…"手动查；开发构建 / 未签名构建没有更新源，这一节是灰的。
- 导出诊断包…：同 帮助 › 导出诊断包…，报问题时附上（[故障排查 › 日志与诊断](故障排查.md#9-日志与诊断)）。

### 高级

| 一节 | 内容 |
|---|---|
| 录制 | **磁盘下限（MB）**：录制目录剩余空间低于这个数就停那一路（默认 200），下一次开录起生效。**备用录制目录**：目标盘满了或低于下限时，从下一拍起切到这个目录接着录（最好在另一块盘上）；"选择… / 清除"，立刻生效 |
| 监听地址 | 本地 API（host:port）、兼容层（host:TCP 端口）：要监听某一个具体地址时在这里填。写错不存，红字说明。需重起引擎 |

## 启动参数

从终端起 App 时可以带（`open PlusMix.app --args …`，或直接执行 `PlusMix.app/Contents/MacOS/PlusMix …`）。启动参数只管这一次运行，不写进本机设置：

| 参数 | 作用 |
|---|---|
| `--show <文件>` | 打开这个节目文件（不恢复上次的） |
| `--stats <文件>` | 每秒一行统计写到这个文件（stats.jsonl） |
| `--audio-device <名字 / default / null>` | 音频输出设备；`null` = 空设备 |
| `--api-listen <host:port>`、`--api-token <token>`、`--no-api` | 本地 API 的地址、令牌、关掉 |
| `--record-min-free-mb <MB>`、`--record-fallback <目录>` | 录制磁盘下限、备用录制目录 |
| `--tally-port <端口>` | 打开只读 tally 流并用这个端口（与无界面引擎同名） |
