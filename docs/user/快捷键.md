# 快捷键、MIDI 与控制面板

所有控制方式发的都是同一套命令（[概念 › 切换是怎么发生的](概念.md#切换是怎么发生的)），所以快捷键、MIDI、Stream Deck、Companion、脚本可以混用，状态永远一致。

## 默认快捷键表

主窗口有焦点时生效（输入框里打字时不触发）。

| 键 | 动作 |
|---|---|
| `1` … `9`、`0` | 把 1–10 号输入选到 PVW（`0` = 10 号） |
| `Shift` + `1` … `0` | 直切 PGM（PVW 不变） |
| `空格` | Cut |
| `回车` | 按已选的转场类型 / 时长执行一次自动转场（默认 Fade 30 拍） |
| `F` | FTB 开 / 关 |

菜单快捷键（AppKit 标准）：⌘N 新建、⌘O 打开、⌘S 保存、⇧⌘S 另存为、⌘I 添加输入、⌘, 偏好设置。

## 改表

切换 › 快捷键…：每行一个组合键 + 一个动作 + 备注；"录键"直接按；同一组合键绑两次会标红并拒绝保存；"恢复默认表"回到上表。

可绑的动作：任何命令（选 PVW / 直切 PGM / Cut / Fade（拍数）/ 按已选转场 / 其他命令），以及看状态的开关：FTB 开关、叠加通道开关、某路静音开关、录制开关、推流开关、AFV 开关。

表存在 `~/Library/Application Support/PlusMix/hotkeys.json`（节目文件之外，换节目不变），格式：

```json
{
  "version": 1,
  "bindings": [
    {"key": "1", "action": {"command": {"setPreview": {"input": 1}}}, "note": "PVW 选 1 号"},
    {"key": "shift+1", "action": {"command": {"setProgram": {"input": 1}}}, "note": "直切 PGM 1 号"},
    {"key": "space", "action": {"command": {"cut": {}}}},
    {"key": "return", "action": {"command": {"autoTransition": {}}}},
    {"key": "f", "action": {"toggleFTB": {}}},
    {"key": "cmd+alt+r", "action": {"toggleRecord": {"output": 1}}},
    {"key": "f5", "action": {"toggleOverlay": {"channel": 1}}}
  ]
}
```

- 组合键写法 `ctrl+alt+shift+cmd+<键>`，顺序随意，也认 `⌘⌥⌃⇧` 前缀和 `command / option / control` 全称；键是单个字母 / 数字 / 符号或命名键：
  `space, return, escape, tab, delete, forwarddelete, up, down, left, right, home, end, pageup, pagedown, f1 … f20`。
- 命令的 JSON 形态与 API 相同（[API 参考](../api.md)）：`{"command": {<命令>}}`。
- 文件读不出来（JSON 错、冲突）时用默认表并在状态行提示。

## MIDI

切换 › MIDI 映射…：CoreMIDI，所有在线设备都监听；面板上 "Learn" 动一下推子 / 按一下键就填好触发。

| 触发 | 动作 |
|---|---|
| CC（7-bit，通道 1–16、控制器 0–127） | T-bar（到两端提交并换向，像真推杆）、某路输入增益、总线增益（值 0–127 线性映射到设定的 dB 范围） |
| 14-bit CC（控制器 0–31 为粗、+32 为细） | 同上，推杆更平滑 |
| Note（按下，力度 > 0） | 与快捷键相同的动作（命令或开关） |

映射表在 `~/Library/Application Support/PlusMix/midi.json`：

```json
{
  "version": 1,
  "mappings": [
    {"trigger": {"cc14": {"channel": 1, "controller": 1}}, "action": {"tbar": {}}, "note": "推杆"},
    {"trigger": {"cc": {"channel": 1, "controller": 7}}, "action": {"busGain": {"bus": 0, "minDb": -60, "maxDb": 0}}},
    {"trigger": {"cc": {"channel": 1, "controller": 16}}, "action": {"inputGain": {"input": 1, "minDb": -60, "maxDb": 12}}},
    {"trigger": {"note": {"channel": 1, "note": 60}}, "action": {"action": {"command": {"cut": {}}}}},
    {"trigger": {"note": {"channel": 1, "note": 61}}, "action": {"action": {"toggleFTB": {}}}}
  ]
}
```

设备拔掉再插回会自动重新监听；App 运行中新接的设备也会被发现。

## Stream Deck、Companion、脚本

- **Stream Deck**：官方 SDK 插件（按钮 = 命令，按钮颜色 = tally），安装与按钮表见 [docs/integrations/stream-deck.md](../integrations/stream-deck.md)。
- **Bitfocus Companion**：走本地 API 的接法（Generic HTTP / WebSocket 模块）见 [API 示例](../api/examples.md#3-companion)；用现成第三方面板配置走兼容层的接法见 [docs/integrations/companion.md](../integrations/companion.md)。
- **外部 tally 灯**：只读的 WebSocket / HTTP tally 流，[docs/integrations/tally.md](../integrations/tally.md)。0.1.0 的 App **不起**这个服务，只有命令行 `switcher-headless` 带 `--tally-port` 时才有；App 里可用的是本地 API 的 `GET /api/v1/tally`（App 内的开关归 prompt 98）。
- **脚本 / 自动化**：HTTP + WebSocket 的本地 API，[docs/api/README.md](../api/README.md)。默认只听 `127.0.0.1:8765`，偏好设置 › 本地 API 可以改地址 / 端口 / token。
