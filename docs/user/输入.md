# 输入

输入 › 添加输入…（⌘I）：左栏选类型，右边填参数，编号自动给下一个空号（可改）。每一路添加后都可以在输入设置 › 来源里换成别的设备，编号、名字、设置和 PGM / PVW / 叠加引用都保留。
八种类型，两种（DeckLink、NDI）依赖可选的第三方 SDK，编译时没探测到 SDK 就只能添加、不能出画面（格子上会写明）。

## 输入的状态

每路输入的格子上除画面之外只有三种状态；分界是"会不会自己好"（[设计方案 §6](../spec/导播台设计方案.md)，用户 2026-09-22 定）：

| 状态 | 意思 | 例子 |
|---|---|---|
| **live** | 在出画面（或纯音频路在出声） | — |
| **noSignal（无信号 / 等待）** | 暂时没有，**会自己好**，格子上写着在等什么 | 设备被拔了、DeckLink 驱动没装、NDI 源还没上线、外接显示器拔了、文件还在开 |
| **error（错误）** | **不会自己好**，要你做点什么 | 权限被拒（去系统设置）、SDK 没编进来（重新编译）、图片不存在（改路径）、起流失败（换配置） |

noSignal 时帧槽保留最后一帧（PGM 上不会闪黑），插回设备、装好驱动、源上线之后自动恢复，不用删了重加，编号和设置都不变。
权限被拒是 error，但授权之后也会自动恢复（每秒轮询），不用重启。

## 摄像头 / 采集卡

走 AVFoundation：内置摄像头、USB / UVC 摄像头和采集卡、iPhone 连续互通相机都在同一个列表里。

- 添加输入面板选"摄像头 / 采集卡"，列表就是系统看到的设备；第一次用会弹摄像头权限。
- 格式协商：先按节目帧率选帧率，再选分辨率（相同 > 都不小于节目的里最小 > 最大），再挑原生 NV12；帧率锁死到协商值。60 fps 节目接 30 fps 摄像头是"设计内重复"，每帧重复一次，不算丢帧。
- 设备自带的麦克风（同一 USB 上的音频）也接进来，**要麦克风权限**；没给就只有画面。
- 热插拔：拔掉 → noSignal，同一个设备插回来 → 自动重建、回到 live；实测恢复 ≤ 3 s。
- 摄像头自己的固定管线延迟（内置相机约 55 ms）不是抖动，引擎按到达时刻挑帧，不用手动补偿；A/V 对不上时用输入设置 › 音频 › 延迟补偿（0–500 ms）。

## DeckLink（SDI / HDMI）

需要 Blackmagic Desktop Video 驱动（`/Library/Frameworks/DeckLinkAPI.framework`）；编译 Switcher 时要有 DeckLink SDK（`DECKLINK_SDK_DIR` 或 `~/SDKs/DeckLink`），没有的话这个输入类型只有空实现（error + 文案）。

- 添加面板列出卡和输入接口（SDI / HDMI / 光纤 SDI / 分量 / 复合 / S-Video）；"不改"= 用 Desktop Video Setup 里设的接口。设备标识 `peid:<持久 ID>`（老卡 `model:<型号>#<序号>`），空 = 第一台有输入的卡。
- 格式自动检测：卡支持的话，信号从 1080p59.94 换成 720p60 会自动重开；无信号帧不进画面（格子保持最后一帧、显示"无信号"），信号回来自动恢复。
- 内嵌音频：卡给 2–16 路，"声道"一栏选取哪两路（见下面"声道映射"）；SDK 只认 2 / 8 / 16 路，要第 6 路时会自动开 8 路。
- 驱动没装：格子显示"没有找到 DeckLink 驱动：安装 Blackmagic Desktop Video 后重试，不用重启本程序"（noSignal，装好会自己好）。
- 状态：真卡上的采集**尚未在本项目的机器上验证**（开发机没有 DeckLink 硬件），桥接层对着 SDK 的模拟设备测过；有卡的人请按 [设备兼容性表](../testing/设备兼容性.md) 报结果。

## 屏幕 / 窗口 / 应用

走 ScreenCaptureKit：整块显示器、单个窗口或某个应用的全部窗口。

- **屏幕录制权限没有系统弹窗**：第一次要自己去 系统设置 › 隐私与安全性 › 屏幕与系统音频录制 里把 Switcher 加上（[故障排查](故障排查.md#1-权限)）。
- 帧率默认跟节目帧率，可以降（抓文档类内容 30 fps 够用，省 GPU）；"同时抓系统音频"把该显示器 / 应用的声音也接进来（排除 Switcher 自己）。
- 画面按 BGRA 原样进合成器（文字不会被 4:2:0 抽色），源比节目大时缩到节目框内。画面静止时按最后一帧重推，不会掉到 noSignal。

## 视频文件

任何 AVFoundation 能解的文件（H.264 / HEVC / ProRes 的 .mov / .mp4 等）。

- 文件按**节目时钟**出帧（时钟从属），播放速率可调；播完：停在末帧 / 循环 / 黑场。
- 音轨解到这一路的音频里，和别的输入一样过推子 / 总线 / AFV。
- 路径写在节目文件里；相对路径相对节目文件所在目录（App 里的现状见 [示例 › 相对路径](../../Samples/README.md#2-相对路径)）。

## 图片

PNG（带 alpha）/ JPEG / HEIC 等。大图预缩放到节目尺寸。

- 带 alpha 的 PNG 叠在叠加通道上就是字幕 / 台标；整幅 1920×1080、透明处透出 PGM 是最省事的做法（[示例](../../Samples/README.md#5-重新生成) 附了三张）。
- 也能当 Stinger 的图层：转场参数里把 stinger 输入指向它，第 n 拍换底。
- 图片输入没有音频。

## NDI 接收

需要 NDI SDK for Apple（默认 `/Library/NDI SDK for Apple`），编译时探测到才有真实现；运行时 SDK 不在则 error + "找不了 NDI 源"。

- 添加面板自动列出网络上的源（名字形如 `机器名 (源名)`），也可以手填；源不在时是 noSignal + "网络上找不到 NDI 源 …（发送端没开、不在同一网段，或名字不对）"，上线后自动接上。
- 带宽模式：最高 / 最低 / 只要音频；只拿来做缩略图的源用"最低"省一半以上带宽和解码。
- 抖动缓冲 0–2 帧，直接决定这一路的延迟（每加 1 帧约多一帧延迟）；默认 1。
- 本机回环（Switcher 自己发、自己收）实测 PGM 到收回来落后 1–2 帧。

## 纯音频设备

Core Audio 输入设备：内置麦克风、USB 声卡、聚合设备、iPhone 麦克风（连续互通）。这种输入**没有画面**。

- 添加面板选设备（"跟随系统默认输入"= 系统设置里换了默认输入会自动重建），多路接口上选取第几路。第一次用要麦克风权限。
- 格子画话筒 + 名字 + 电平表；能被选进 PGM / PVW / 叠加，画面按黑场画、声音照常按 AFV 走；多画面里它的格子也是名字 + 电平表。
- 设备固定到 48 kHz，做不到才转换（面板上会标"不支持 48 kHz，会转换"）。拔掉 → noSignal + "已断开，等待重新连接"，插回 ≤ 3 s 恢复。

## 合成测试源

引擎内置：每帧烧入帧号、时间戳、输入 ID、每秒一次的闪光块，可选合成音频（1 kHz −20 dBFS + 与闪光同刻的 click）。
参数：帧率（30 / 59.94 / 60）、底色（纯灰 / 渐变 / 灰底噪声）、人为抖动、人为丢帧、时钟漂移、音频漂移。
用途：没设备时搭节目（[示例节目](../../Samples/README.md)全用它）、验证 A/V 对齐、给编码器真实负载（选噪声底纹）。[测试标准 §2.1](../testing/测试标准.md#21-合成视频源)有它的全部定义。

## 每路输入的设置

缩略图右键"设置…"或输入 › 输入设置…：

| 一节 | 内容 |
|---|---|
| 基本 | 名字、编号 |
| 来源 | 换设备 / 文件 / 源名，"应用来源"后重建这一路 |
| 裁切 / 变换 | 四边裁切（比例）、缩放、平移、旋转、翻转 |
| 音频 | 送哪几条总线、增益、静音、独听、声像、延迟补偿 0–500 ms、跟随视频（AFV） |
| 效果链 | 每路的效果格（占位，顺序 = 处理顺序） |
| 抠像 | 键色、容差、柔化、溢色抑制；对这一路出现的每一处（PGM、转场、叠加、PVW、多画面）都生效 |

超出范围的值会被钳住（增益 −96…+24 dB、延迟 0–500 ms、裁切对边之和 ≤ 1）。

### 声道映射（DeckLink 内嵌音频、纯音频设备）

"声道"一栏决定源的哪几路写进这一路的左 / 右：

- 前两路（默认）：左 = 第 1 路、右 = 第 2 路；源是单声道就两边都给它。
- 单声道：一路给两边（单声道话筒插在第 5 路 → 选"第 5 路"）。
- 选两路：左 / 右各选一路。

越界的下标钳到源的声道范围里。改映射等于换设备，这一路会重建。
