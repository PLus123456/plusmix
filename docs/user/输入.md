# 输入

## 添加输入

入口：输入 › 添加输入…（⌘I）、底栏"添加输入…"（主体 = 面板；▴ = 按类型直达或一键再加"最近添加"的来源）、输入条末尾的"＋ 添加输入"格子，或者直接把视频 / 图片文件[拖进输入条](#拖文件进来)。

面板左栏按用途分组，每一页第一行写着它能接什么、要什么前提：

| 组 | 类型 |
|---|---|
| 设备 | 摄像头 / 采集卡、DeckLink、音频设备 |
| 网络 | NDI® |
| 屏幕 | 屏幕 / 窗口 / 应用 |
| 媒体 | 视频文件、图片 |
| 测试 | 合成测试源 |

- 第一次打开停在"摄像头 / 采集卡"；之后停在上次添加用的类型，**每一类上次加的来源**（摄像头、文件、NDI® 源名和带宽、音频设备和声道、抓哪块屏……）都预填好。记住的摄像头 / 显示器不在了就退到列表第一个（音频设备写"（不在）"）。
- 编号默认给最小的空号（可改，只列空号；已有的输入不会挪号）。一个节目最多 16 路，满了"添加"灰着、写"本节目的输入已满（16 路）"。
- 面板可以拖大，下次照这个大小开。
- 每一路添加后都可以在 输入设置 › 来源 里换成别的设备，编号、名字、设置和 PGM / PVW / 叠加引用都保留。
- 两种类型（DeckLink、NDI®）依赖可选的第三方 SDK，编译时没探测到 SDK 就只能添加、不能出画面（格子上会写明）。

**横幅**：权限被拒、运行库没装时，面板那一页顶上有一条横幅，照样能加（"添加"旁写"加上后先显示错误，授权后自动恢复"）：

| 情况 | 横幅上的按钮 |
|---|---|
| 摄像头 / 麦克风 / 屏幕录制权限被拒 | "打开系统设置…"：直达 系统设置 › 隐私与安全性 里对应那一页 |
| NDI® 运行库不在、这一版没带 DeckLink 支持、DeckLink 驱动没装 | "看说明"：打开本手册的对应一节 |

还没问过的权限不挂横幅——第一次加的时候系统自己会问。授权、装好之后回到面板，横幅按新状态刷新。
注意："NDI® 运行库不在"和"这一版没带 DeckLink 支持"说的是**这份 App 编译时没带那个 SDK**，加上的那一路会一直报错，要换一份带 SDK 编的 App（NDI® 横幅上"装好之后这一路会自己好"那句不成立）；"DeckLink 驱动没装"是真的装好驱动、插上卡就自己好。

## 输入的状态

每路输入的格子上除画面之外只有三种状态；分界是"会不会自己好"（[设计方案 §6](../spec/导播台设计方案.md)，用户 2026-09-22 定）：

| 状态 | 意思 | 例子 |
|---|---|---|
| **live** | 在出画面（或纯音频路在出声） | — |
| **noSignal（无信号 / 等待）** | 暂时没有，**会自己好**。格子上只写"无信号"（纯音频输入写"等音频设备…"），不写在等什么——原因按 [故障排查 › 无信号](故障排查.md#2-无信号) 逐项查 | 设备被拔了、DeckLink 驱动没装、NDI® 源还没上线、外接显示器拔了、文件还在开 |
| **error（错误）** | **不会自己好**，要你做点什么；格子上写原因（例如"摄像头权限被拒。打开 系统设置 › 隐私与安全性 › 摄像头，允许本程序后会自动恢复，不用重启。"） | 权限被拒（去系统设置）、SDK 没编进来（重新编译）、文件 / 图片不存在（改路径）、起流失败（换配置） |

noSignal 时帧槽保留最后一帧（PGM 上不会闪黑），插回设备、装好驱动、源上线之后自动恢复，不用删了重加，编号和设置都不变。
权限被拒是 error，但授权之后也会自动恢复（每秒轮询），不用重启。

## 摄像头 / 采集卡

走 AVFoundation：内置摄像头、USB / UVC 摄像头和采集卡（HDMI / SDI 转 USB）、iPhone 连续互通相机都在同一个列表里。

- 第一次用会弹摄像头权限。
- 格式协商：先按节目帧率选帧率，再选分辨率（相同 > 都不小于节目的里最小 > 最大），再挑原生 NV12；帧率锁死到协商值。
  面板上直接写结果，例如"将以 1920×1080 · 60 fps 采集（与节目帧率一致）"；对不上时标黄并写后果："比节目慢，会重复帧"或"比节目快，会丢帧"，分辨率不同写"（缩放到 …）"。
  60 fps 节目接 30 fps 摄像头是"设计内重复"，每帧重复一次，不算丢帧（MacBook Pro 内置摄像头最高 30 fps，在 60p 节目里就是黄的，这是对的）。
- 设备自带的麦克风（同一 USB 上的音频）也接进来，**要麦克风权限**；没给就只有画面。
- 热插拔：拔掉 → noSignal，同一个设备插回来 → 自动重建、回到 live；实测恢复 ≤ 3 s。
- 摄像头自己的固定管线延迟（内置相机约 55 ms）不是抖动，引擎按到达时刻挑帧，不用手动补偿；A/V 对不上时用 输入设置 › 音频 › 音频延迟补偿（0–500 ms）。

## DeckLink

Blackmagic DeckLink / UltraStudio 采集卡上的 SDI / HDMI 口。需要 Blackmagic Desktop Video 驱动（`/Library/Frameworks/DeckLinkAPI.framework`）；编译 PlusMix 时要有 DeckLink SDK（`DECKLINK_SDK_DIR` 或 `~/SDKs/DeckLink`），没有的话这个输入类型只有空实现（error + 文案）。

- 添加面板列出卡和输入接口（SDI / HDMI / 光纤 SDI / 分量 / 复合 / S-Video）；"不改"= 用 Desktop Video Setup 里设的接口。设备标识 `peid:<持久 ID>`（老卡 `model:<型号>#<序号>`），空 = 第一台有输入的卡。
- 格式自动检测：卡支持的话，信号从 1080p59.94 换成 720p60 会自动重开；无信号帧不进画面（格子保持最后一帧、显示"无信号"），信号回来自动恢复。
- 内嵌音频：卡给 2–16 路，"声道"一栏选取哪两路（见[声道映射](#声道映射decklink-内嵌音频纯音频设备)）；SDK 只认 2 / 8 / 16 路，要第 6 路时会自动开 8 路。
- 驱动没装：格子写"无信号"（noSignal），装好 Blackmagic Desktop Video、插上卡会自己好，不用重启。这份 App 编译时没带 DeckLink SDK 的话，格子写"DeckLink SDK 未编译进来：…后重新编译"（error）。
- 状态：真卡上的采集**尚未在本项目的机器上验证**（开发机没有 DeckLink 硬件），桥接层对着 SDK 的模拟设备测过；有卡的人请按 [设备兼容性表](../testing/设备兼容性.md) 报结果。

## 屏幕 / 窗口 / 应用

走 ScreenCaptureKit：整块显示器、单个窗口或某个应用的全部窗口（放幻灯片、浏览器、远程连线窗口）。

- **屏幕录制权限没有系统弹窗**：第一次要自己去 系统设置 › 隐私与安全性 › 屏幕与系统音频录制 里把 PlusMix 加上（[故障排查](故障排查.md#1-权限)）；面板上的横幅有"打开系统设置…"直达。
- 面板上是缩略图网格：显示器随时列出；窗口 / 应用的列表和截图要先有屏幕录制权限（没权限时只画图标）。
- 帧率默认跟节目帧率，可以降（抓文档类内容 30 fps 够用，省 GPU）；"同时抓系统音频"把该显示器 / 应用的声音也接进来（排除 PlusMix 自己）。
- 画面按 BGRA 原样进合成器（文字不会被 4:2:0 抽色），源比节目大时缩到节目框内。画面静止时按最后一帧重推，不会掉到 noSignal。

## 视频文件

任何 AVFoundation 能解的文件（H.264 / HEVC / ProRes 的 .mov / .mp4 等）。

- 文件按**节目时钟**出帧（时钟从属），播放速率可调；播完：停在末帧 / 循环 / 黑场。暂停、回到开头、切上 PGM 时从头播见下面的[播放](#播放)。
- 面板上有"最近用过"（最多 10 个，新的在前；单击填入、双击直接添加；文件不在了灰着写"（不在了）"）；选好文件就显示它的信息，例如"H.264 · 1920×1080 · 60 fps · 0:10"（没有声音、含透明通道也写出来）。
- 音轨解到这一路的音频里，和别的输入一样过推子 / 总线 / AFV。
- **纯音频文件**（mp3 / wav / m4a / aac）：打开面板收它们，信息写"纯音频 · …"，格子按纯音频画；但**这一版的文件输入还要求有画面**，加上之后格子会显示"文件里没有视频轨"。
- **只改"播完"或"播放速率"当场生效、不重建**：格子上的 🔁、输入设置 › 来源 里改这两项，这一路接着播（不从头来、画面不断），不用点"应用来源"；换文件、换类型才要"应用来源"（这一路重建，画面断一下，从头播）。
- 加的时候文件不在（格子报"文件不存在：…"）：文件放好之后要删掉这一路重新加，或重新打开这个节目——视频文件不会像图片那样自己换上。
- 路径写在节目文件里；相对路径相对节目文件所在目录（没保存过的节目相对 `~/Movies/PlusMix`，[示例 › 相对路径](../../Samples/README.md#2-相对路径)）。

### 播放

视频文件输入的格子第一行后三颗、右键菜单、输入设置 › 来源 下面的"播放"一节是同一组动作（别的输入上这三颗灰着，悬停写"只对视频 / 音频文件输入"）；
只有一处不同：输入设置窗"播放"一节的 ▶ / ⏸ 只看暂停没暂停，不认"播完了"——播完之后要从头播，在那里点"⏮ 回到开头"。

| 按钮 | 做什么 |
|---|---|
| ⏮ 回到开头 | 播着就从头播；暂停着就停在第一帧（还是暂停） |
| ⏸ / ▶ | 播着显示 ⏸：点 = **暂停**，画面停在这一帧（仍每拍出帧，格子不写"无信号"）；暂停中显示 ▶ 并高亮：点 = 从停住的地方接着播；播完了（没开循环）显示 ▶：点 = 从头播。播完停在末帧（或变黑场）时格子写"无信号"，暂停不算 |
| 🔁 循环 | 开 = 循环播放（高亮）；**关 = 播完停在最后一帧**。要播完变黑场，去 输入设置 › 来源 把"播完"改成"黑场"（当场生效）。已经播完停在末帧之后再打开循环 = 当场从头接着循环 |

- **切上 PGM 时从头播**（右键菜单里打勾，或 输入设置 › 来源 › 播放）：这一路被切上 PGM 的那一拍（Cut、转场做完、T-bar 推到顶、API `setProgram`）从头播，在 PVW 上预览时不动；
  首帧比切换那一拍晚几拍（App 里实测约 3 拍，60p 下 50 ms；界面提示写的"1–2 拍"只算了引擎定位那一段），这几拍 PGM 上定在这一路切换前的最后一帧；暂停中切上去 = 回到第一帧、仍暂停。这一项随节目保存（改了算未保存）。
- 暂停 / 回到开头是现场操作，不算未保存的改动；换文件、"应用来源"重建这一路后从头播。
- 对应的命令是 `setPlayback`、`seekPlayback`（[API 参考](../api.md)），快捷键 / MIDI 能绑（选动作面板"输入"组的"文件播放 / 暂停""文件定位 / 从头播"）。

## 图片

PNG（带 alpha）/ JPEG / HEIC 等。大图预缩放到节目尺寸。

- 带 alpha 的 PNG 叠在叠加通道上就是字幕 / 台标；整幅 1920×1080、透明处透出 PGM 是最省事的做法（[示例](../../Samples/README.md#5-重新生成) 附了三张）。
- **一次选多张**：浏览面板里多选，每张加一路，名字用文件名（第一张用面板上选的编号，其余依次取空号；空号不够就一路都不加并写原因）。
- **文件在外面改了会自动换上**：在图片软件里改好存盘（覆盖或替换都行），PGM 上下一拍就换成新图，不闪黑、这一路不重建。
  加的时候文件还不在也没关系：格子先报"图片不存在：…"，文件放到位后自己换上（每 0.25 s 看一次）。
- 也能当 Stinger 的图层：转场参数里把 Stinger 输入指向它，第 n 拍换底。
- 图片输入没有音频（格子上的"静音"是灰的）。

## NDI® 接收

同一个局域网里其他电脑 / 设备发出的 NDI® 画面（带声音）。需要 NDI SDK for Apple（默认 `/Library/NDI SDK for Apple`），编译时探测到才有真实现；没探测到的构建里格子写"NDI SDK 未编译进来：…后重新编译"（error，添加面板的 NDI® 页写"找不了 NDI 源：…"）。（NDI® is a registered trademark of Vizrt NDI AB.）

- 面板开着这一页时每 4 s 重找一次（找的时候转圈），列出网络上的源（名字形如 `机器名 (源名)`），**双击直接添加**；也可以手填。
  源不在时是 noSignal（格子写"无信号"：发送端没开、不在同一网段，或名字不对），上线后自动接上。
- 带宽模式：最高（全分辨率）/ 最低（预览流）/ 只要音频；只拿来做缩略图的源用"最低"省一半以上带宽和解码。
- 抖动缓冲 0–2 帧，直接决定这一路的延迟（每加 1 帧约多一帧延迟）；默认 1。
- 本机回环（PlusMix 自己发、自己收）实测 PGM 到收回来落后 1–2 帧。

## 纯音频设备

Core Audio 输入设备：内置麦克风、USB 声卡、聚合设备、iPhone 麦克风（连续互通）、调音台的 USB 输出。这种输入**没有画面**。

- 面板上的设备写成"MacBook Pro 麦克风（1 声道 · 内建）"这样（声道数 · 连接方式）；"系统默认输入"= 系统设置里换了默认输入会自动重建；多路接口上选取第几路。第一次用要麦克风权限。
- 格子画话筒 + 名字 + 电平表；能被选进 PGM / PVW / 叠加，画面按黑场画、声音照常按 AFV 走；多画面里它的格子也是名字 + 电平表。
- 设备固定到 48 kHz，做不到才转换（面板上会标"不支持 48 kHz，会转换"）。拔掉 → noSignal（格子写"等音频设备…"），插回 ≤ 3 s 恢复。

## 合成测试源

引擎内置：每帧烧入帧号、时间戳、输入 ID、每秒一次的闪光块，可选合成音频（1 kHz −20 dBFS + 与闪光同刻的 click）。
参数：帧率（30 / 59.94 / 60）、底色（纯灰 / 渐变 / 灰底噪声）、人为抖动、人为丢帧、时钟漂移、音频漂移。
用途：没设备时搭节目（[示例节目](../../Samples/README.md)全用它）、验证 A/V 对齐、给编码器真实负载（选噪声底纹）。[测试标准 §2.1](../testing/测试标准.md#21-合成视频源)有它的全部定义。

## 输入条与格子

主窗口中间那一条。头一行从左到右：

- **分类标签**："全部"+ 六种颜色（红、橙、黄、绿、蓝、紫）。点一种颜色 = 只显示这一类，再点一次 = 回到全部；和搜索叠加。右键一种颜色 = 改名… / 清除名字（起了名的标签写名字）。
  给某一路分类：格子右键 › 分类 ▸。分类存在节目文件里（改了算未保存）；删掉一路时它的分类跟着清。这一版分类只在 App 里，API、多画面、控制面板看不到。
- **搜索框**：按编号或名字筛，⌘F（输入 › 搜索输入）把光标放进去；回车把焦点还给主窗口（筛选留着），Esc 还焦点并清掉筛选——之后快捷键照常。
- 右端"**调音台**"：显示 / 收起调音台（和 窗口 › 调音台 同一个开关，开着高亮）。

### 格子

每路输入一个格子：标题条（编号、名字、分类色点；在 PGM 上红底、在 PVW 上绿底）、缩略图（所有格子一样高，按多画面里格子的比例算、不高于 16:9，不留黑边）、两行按钮。
第一行 × ｜ 转场 ｜ Cut ｜ ⏮ ｜ ▶⏸ ｜ 🔁，第二行 1 2 3 4 ｜ 静音 ｜ ⚙：

| 按钮 | 做什么 |
|---|---|
| × | 删除这一路。它在 PGM / PVW / 开着的叠加通道 / Stinger / 正在录的 ISO 上时先确认，逐条写后果（"它在 PGM 上：删掉后 PGM 会变成黑场"……）；别的情况直接删。删除不能撤销 |
| 转场 | 按**当前转场槽**把这一路送上 PGM（不在 PVW 上时先选进 PVW）——和回车、T-bar、菜单"执行当前转场"用的是同一个槽（[概念 › 转场槽](概念.md#转场槽)）。悬停写当前槽，例如"按当前转场送上 PGM（转场 1 · Fade 0.5 秒）" |
| Cut | 直切到 PGM（不经过 PVW） |
| ⏮ ▶⏸ 🔁 | 回到开头 / 暂停·继续 / 循环，只对视频文件亮（别的输入灰着）；见[视频文件 › 播放](#播放) |
| 1 2 3 4 | 把这一路放到叠加通道 n 并打开；它已经开在这个通道上时 = 关。右键 = 叠加设置… |
| 静音 | 静音 / 取消静音这一路；没有声音的输入（图片、没开声音的屏幕采集、没开音频的合成源）灰着，悬停写原因 |
| ⚙ | 这一路的输入设置（也可以右键 › 设置…） |

最小的格子（160 pt 宽）里六颗也放得下：⏮ ▶⏸ 🔁 是 20 pt 的图标，"转场""Cut"平分剩下的宽度。

- **点缩略图** = 选进 PVW；**Shift 点** = 直切 PGM。
- **转场进行中**（T-bar 推到一半也算）"转场"和"Cut"都是灰的，点缩略图、Shift 点也不生效，状态行提示"转场进行中：等这次转场做完再改 PVW / PGM"——
  转场中改 PVW / PGM 会被状态机拒绝（见 [概念 › 切换是怎么发生的](概念.md#切换是怎么发生的)）。已经在 PGM 上的那一路，"转场 / Cut"也是灰的。
- **右键菜单**：送到 PVW ／ Cut 到 PGM ／ 按当前转场送上 PGM（转场 1 · Fade 0.5 秒）／ Overlay ▸ 1–4 ／ 分类 ▸ ／ 静音 ─〔视频文件输入多四项：播放（或暂停）／ 回到开头 ／ 循环（打勾）／ 切上 PGM 时从头播（打勾）─〕设置… ／ 换来源…（直接打开输入设置的"来源"一节）／ 重命名… ─ 删除输入 n。

### 拖文件进来

从 Finder 把视频 / 图片文件拖到输入条或"＋ 添加输入"格子上：每个文件直接加一路，不弹面板。编号依次取空号，名字用文件名；视频 = 文件输入（循环、1 倍速），图片 = 图片输入。
拖进来时整条描蓝边；不是视频 / 图片的文件跳过，状态行写"跳过 1 个不是视频 / 图片的文件：…"；号用满就停下并提示。拖进来的也记进"最近添加"。

### "＋ 添加输入"格子与缩略图大小

- 输入条末尾总有一个虚线格"＋ 添加输入"，单击 = 添加面板（同底栏"添加输入…"）；空节目时它是唯一一格，框里多一行"也可以把视频 / 图片文件拖到这里"。
- 缩略图三档：小 / 中 / 大（格子宽 160 / 200 / 256）。输入条空白处右键 › 缩略图大小 ▸，或 窗口 › 输入缩略图 ▸。存在本机，换大小后输入条贴回格子的高度。

## 每路输入的设置

打开"输入 n 设置 — 名字"窗：格子上的 ⚙ 或右键 › 设置…、监视器标题条的齿轮（PVW / PGM 上那一路）、输入 › 输入 N「名字」设置…（⇧⌘I，PVW 上那一路）。
每路一个窗，可以同时开几个；开着时按快捷键照样切画面。标题行写编号、名字和 tally（"在 PVW / 在 PGM"），右下角是这一路的实时画面（多画面缩略图那一格，画质是缩略图级），纯音频输入写"没有画面"。

| 一节（按左栏顺序） | 内容 |
|---|---|
| 基本 | 名字（改完离开这一栏、按回车或关窗就改名）、编号、类型 |
| 抠像 | 启用、键色、"在画面上取色"（点一下右下的画面，取那一点周围 3×3 像素的平均作键色）、容差、边缘柔化、溢色抑制、恢复默认；对这一路出现的每一处（PGM、转场、叠加、PVW、多画面）都生效 |
| 裁切与位置 | 四边裁切（%）、缩放、水平 / 垂直平移、旋转、水平 / 垂直翻转；滑杆旁可以直接输数字，每项有复位（↺），整组复位；"复制位置 / 粘贴位置"在几路之间抄裁切和位置 |
| 音频 | 送哪些总线、增益、静音、独听（送耳机）、声像、音频延迟补偿（ms，0–500，只推迟声音）、**跟随视频（AFV）**（与调音台条子上的同一个开关；调音台头部的 AFV 总开关关着时不起作用）、复位增益 / 声像 / 延迟 |
| 音频效果 | 参数均衡（最多 3 段）、压缩器（"用压缩"：阈值 / Headroom / 扩展比 / 起音 / 释放 / 输出增益）、限幅器；改了**立刻作用到这一路的声音**（与调音台这一路的音频设置窗是同一份设置）。处理顺序固定先均衡后压缩；**"限幅器"那一节对每路不起作用**（每路不装限幅，只有总线有）。经 API 写进来的 `compressor` 等这里不认的效果列在"其他效果（原样保留）"下，只显示、不能改。口径见 [概念 › 音频](概念.md#音频) |
| 来源 | 换类型 / 设备 / 文件 / 源名 / 播完动作 / 速率；"应用来源"后这一路按新来源重建（画面断一下，文件从头播），"改回"放弃没应用的改动；来源没改时"应用来源"是灰的。视频文件**只改"播完"或"播放速率"当场生效、不重建**（接着播），不用点"应用来源"。视频文件下面多一节"播放"：▶ 播放 / ⏸ 暂停、⏮ 回到开头、切上 PGM 时从头播（同格子上的按钮与右键，见[播放](#播放)） |

左栏底部"**从其他输入复制…**"：选一路，勾要抄的几组（裁切与位置 / 抠像 / 音频 / 音频效果），一次覆盖到这一路。

超出范围的值会被钳住（增益 −96…+24 dB、延迟 0–500 ms、裁切对边之和 ≤ 1）。

### 声道映射（DeckLink 内嵌音频、纯音频设备）

"声道"一栏决定源的哪几路写进这一路的左 / 右：

- 前两路（默认）：左 = 第 1 路、右 = 第 2 路；源是单声道就两边都给它。
- 单声道：一路给两边（单声道话筒插在第 5 路 → 选"第 5 路"）。
- 选两路：左 / 右各选一路。

越界的下标钳到源的声道范围里。改映射等于换设备，这一路会重建。
