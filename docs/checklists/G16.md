## 0. 准备

- 起 App：`DEVELOPMENT_TEAM=59554R22ZM make gen build-app`，然后从 Terminal.app 打开 `.build/DerivedData/Build/Products/Debug/PlusMix.app`（开发签名，摄像头 / 屏幕录制授过权就不再问）。
- 加 12 路左右的输入，够看折行就行：底栏"添加输入 ▴"› 合成测试源，连加几次；或者直接打开一个你平时用的节目。
- 窗口大小可以手拉，也可以在终端里摆准：`osascript -e 'tell application "System Events" to set size of window 1 of process "PlusMix" to {1440, 900}'`。
- 下面"上边"指两个监看（PVW 在左、PGM 在右）加中间那一列（Cut、转场 1–4、FTB、叠加、T-bar、时钟），"下边一行"指输入区加调音台。

## 1. 四种窗口大小各拉一遍（节目格式 1920×1080）

每种大小都应该是：两个监看横贯整个窗口宽度，**监看框就是画面的形状，框里四周没有黑边**；调音台在右下，和输入区一样高；输入区的格子一行放不下就折到下一行，格子之间和两头的空隙一样大。

- [ ] **1100×720（最小）**：中间那一列没有时钟、没有"当前槽"和"时长"两行（Cut、转场 1–4、FTB、叠加、T-bar 都在）；时间改在最底下状态行的右端，小字 HH:mm:ss，每秒走；输入一行，露出 3 路（收起调音台后 5 路），其余往下滚得到。
- [ ] **1440×900**：中间那一列是全的、带时钟；监看下面最多空一条细缝（4 pt）；输入两行，露出 10 路（收起调音台 12 路）。
- [ ] **1728×1117**（16 寸笔记本屏全屏那么大）：全的、带时钟；输入三行，16 路以内全露出。
- [ ] **拉到这块屏能拉的最大**：监看跟着变大、始终贴合；下边一行更高，调音台的推子跟着变长。
- [ ] 从最小慢慢拉到最大再拉回来：时钟、"当前槽 / 时长"两行按高度自己出来、自己收回去，过程中没有东西叠在一起或被裁掉；同一个大小不管是拉大拉到的还是缩小缩到的，样子一样。

## 2. 换节目格式（设置 › 节目格式）

每换一种，监看框都立刻变成那个形状、里面不留黑边。

- [ ] **16:9（1920×1080）**：同第 1 节。
- [ ] **竖屏（预设里选 1080×1920，或点"横 ⇄ 竖"）**：两个监看占满左边整个高度；右边一栏上面是输入区、下面是调音台，两者同宽；输入格子变成竖的小格（标题条 + 竖的缩略图，没有按钮行）；窗口 1440×900 时小格 5 列 × 2 行。"横 ⇄ 竖"再点一次回到横屏；预设里有 1080×1920、720×1280、2160×3840 三个竖屏项。
- [ ] **2460×1080（你那面 20.5:9 的墙，分辨率选"自定义"填进去）**：两个监看仍并排；窗口 1440×900 时中间那一列收起时钟（时间在状态行右端）、监看下面空不超过 20 pt 左右；输入格子比 16:9 时矮一些，三行、露出 15 路上下。
- [ ] **5760×1080（三块 16:9 连成的墙）**：两个监看改成**上下叠放**（PVW 在上、PGM 在下，每幅用到整个宽度），中间那一列挪到右边；下边一行至少露出两行输入。在外接屏上把窗口高度留在 900 左右、慢慢拉宽：到大约 2380 宽时换回并排，再缩回来要到 2240 左右才换回叠放——中间那一段不来回跳（笔记本屏不够宽，一直是叠放）。

## 3. 调音台

- [ ] **收起 / 展开**（输入区右上角的"调音台"开关，或 窗口 › 调音台）：收起后输入区占满整行、露出的路数变多；展开后回到原来的宽度；监看不动。
- [ ] **窗口缩到最小时**：调音台够高就是整条（声像、总线送出、跟随视频三行都在）；竖屏 + 最小窗口时调音台变成紧凑条——只剩名字、表、推子、读数、静音和独听，那三行收进每条的齿轮菜单里，点齿轮能改。

## 4. 两条分隔条

- [ ] **上下之间那条**：往上拖，下边一行变高、两个监看等比变小并居中（框里仍没有黑边）；往下拖，拖到监看贴合的高度就拖不动了（不会拖出一片空白）；拖回到底 = 回到自动排的样子。
- [ ] **"输入 ｜ 调音台"之间那条**：往左拖调音台变宽，退出重开还记得；往右拖最窄到 340；再往右拖过一半，调音台收起。
- [ ] 竖屏时这两条线不能拖（这一版就是这样，已知）。

## 5. 时钟的三个选项（设置 › 常规 › 显示 › 时钟）

- [ ] **自动**（默认）：就是第 1、2 节看到的——放得下就在中间那一列，放不下就收到状态行右端。
- [ ] **一直显示**：窗口缩到最小时钟也留在中间那一列（监看下面会空出一截，这是选了它的代价）。
- [ ] **不显示**：窗口再大中间那一列也没有时钟，时间一直在状态行右端。
- [ ] 改完退出重开，选项还在。

## 6. 旧排布开关（窗口 › 排布）

- [ ] 选**旧排布**：回到改之前的样子——调音台在右侧从上到下通高，监看框里画面四周有黑边，输入条只有一行、横着滚。当前选的那一项前面打勾。
- [ ] 选回**新排布**：回到第 1 节的样子；调音台原来开着的还开着、收着的还收着；在录在推的不受影响。
- [ ] 退出重开，记得上次选的排布。

## 7. 竖屏小格怎么点

节目格式换成 1080×1920 后在右边的输入小格上试：

- [ ] **点一下** = 这一路进 PVW（标题条变绿）。
- [ ] **按住 ⇧ 点** = 直接切上 PGM（标题条变红）。
- [ ] **右键** = 和横屏格子右键同一份菜单（送 PVW、Cut 到 PGM、按已选转场送上 PGM、Overlay 1–4、分类、静音、设置…、换来源…、重命名…、删除…）；小格上没有按钮，动作都在这里。
- [ ] 窗口 › 缩略图大小 那四项在竖屏时是灰的（竖屏固定用小格）；换回横屏后能选，第四项"紧凑"就是这种小格。

## 8. 打开一个老节目

- [ ] 打开一个改版之前存的节目文件（或 Samples/ 里任一个）：正常打开，监看框是这个节目格式的形状，输入、调音台、转场槽、叠加都在；保存再打开没有变化（排布开关、分隔条位置、时钟选项存在本机，不进节目文件）。
