# G4 人工检查清单（M4 输入二期 + M6 叠加、转场、其它输出）

落地方案 §4 G4 的人工部分，G4 prompt 第 3 条。每条写"怎么做 / 看什么 / 过的标准"，做完在方框里打勾并把看到的数字填在后面。
前提：`make gate4`（或至少 `make build`）跑过；`make gen build-app` 编出 `.build/DerivedData/Build/Products/Debug/Switcher.app`。
**签名 / 权限相关的项要从 Terminal.app 起 App**（从 Claude 的 Bash 起的进程拿不到摄像头 / 屏幕录制 TCC，G3 的经验），
虚拟摄像头那一条还要 Team ID（`DEVELOPMENT_TEAM=<TeamID> make gen build-app`，权限表自动换成 App/Switcher-signed.entitlements）。
本机条件（G4 时）：只有内置屏、没有 DeckLink 卡 / 驱动、没有 Companion / Stream Deck、`security find-identity -p codesigning` 0 个身份。

## 1. Add Input 每种类型走一遍（W3-E 的八种 + W3-A 的两种运行实现）

底栏"添加输入…"（⌘I）左栏依次选：

- [ ] **合成源**：60 fps、带音频、噪声 ±24 → 格子出画面、tally 边框对、状态行 fps 60。
- [ ] **摄像头 / 采集卡**：内置摄像头 → ≤ 5 s 出画面（第一次弹 TCC 授权；从 Terminal.app 起才会弹）。
- [ ] **DeckLink**：设备列表为空时手填任意标识（例如 `peid:1`）→ 添加后格子显示 **"没有找到 DeckLink 驱动：安装 Blackmagic Desktop Video（/Library/Frameworks/DeckLinkAPI.framework）后重试，不用重启本程序"**（状态 noSignal，等设备；App 不崩，编号保留）。
      有卡的机器：格子 ≤ 3 s 出画面，拔线 → "无信号"，插回自动恢复。文案不清楚 / 状态是 error 而不是 noSignal → 记下来退 W3-A。
- [ ] **屏幕 / 窗口 / 应用**：选"整块显示器" → 出画面（第一次要屏幕录制授权）；选"单个窗口"列表能列出窗口。
- [ ] **视频文件**：`Tests/Fixtures/pattern.mov` 循环 → 帧号块在走，播完从头。
- [ ] **图片**：`scenarios/g4-stinger.png` → 格子里透明区显示黑、下方蓝色横幅 + 橙色斜线、两侧立柱（alpha 保留；这张图后面第 4 条 Stinger 要用，编号记下：____）。
- [ ] **NDI**：源列表为空时手填 `不存在的机器 (Nope)` → 格子显示 **"网络上找不到 NDI 源 …（发送端没开、不在同一网段，或名字不对）"**（noSignal，等源出现）。
      有 NDI 源的网络（或另开终端 `switcher-headless run --show scenarios/g4-ndi-show.json --duration 300 --ndi-send "Switcher G4 loop" --audio-device null`，它会在网络上发一个源）：选中 → ≤ 3 s 出画面、延迟感 ≈ 2 帧（抖动缓冲 1 帧）。
- [ ] **纯音频设备**：选一个有输入声道的设备 → 添加后提示"不支持的输入类型"（W3-A 没做纯音频输入的运行实现，这是已知项，见 reports/G4.md §3），App 不崩。
- [ ] 添加完 8 路以上，多画面格子自动 6×3；缩略图右键"设置…"六节都能开。

## 2. Overlay 1–4 各挂一个源：开关、动画、PVW 预览

打开 `scenarios/g4-show.json`（节目 › 打开；输入 9 的图片路径相对节目文件，App 里若显示找不到，用第 1 条添加的图片输入替换 Stinger 参数即可）。

- [ ] 底栏"叠加…"：通道 1–4 已分别挂 5 / 6 / 7 / 8 号（左下 / 右下 / 左中 / 右中）。逐个打开：1 淡入 15 拍（0.25 s）、2 从底边滑入 20 拍、3 绕中心放大 20 拍、4 直接出现。关掉走反向动画。
- [ ] 四个同时开：PGM 四角各一个画中画，位置 / 大小与面板里的 x y w h 一致；改 x 立刻生效。
- [ ] 换通道 2 的输入为 1 号 → 画中画内容立刻换；把通道 3 的位置改成"下三分之一"预设 → 整幅宽 / 高 1/3 贴底。
- [ ] **PVW 预览**：默认 PVW 不画叠加（提案 010 过渡口径 `overlaysInPreview` 关）；把 PVW 切到某路后叠加只出现在 PGM 上。要在 PVW 上预览叠加的需求记到提案 010。
- [ ] 输入设置 › 效果链给 5 号加一格 `border`（width 6，color 白）→ 画中画有白边（W3-B 的过渡做法，提案 010 正式字段前）。

## 3. 绿幕素材抠像调参

- [ ] 加一路视频文件输入（自备绿幕素材；没有的话用摄像头对着一张绿纸 / 绿色屏幕）。输入设置 › 抠像：打开，键色取绿（默认 0,255,0 或用取色器点绿幕）。
- [ ] 容差 0.3 → 背景抠掉、前景完整；调到 0.1 背景残留、调到 0.6 前景边缘被吃（W3-B 的口径：半径 = tolerance × 0.5）。柔化 0 → 硬边锯齿，0.3 → 边缘柔；溢色抑制 0 → 边缘发绿，1 → 边缘中性。
- [ ] 把这路挂到 Overlay 1 叠在 PGM 上：透明处露出 PGM；多画面缩略图里同样透明（缩略图是滤波后抠一次，边缘可能比 PGM 略糙，这是设计使然）。
- [ ] 记录一组满意的参数：容差 ____ 柔化 ____ 溢色 ____（写进 reports/G4.md §人工检查）。

## 4. Wipe / Zoom / Stinger 各切一次；T-bar 手推 Wipe

先打开 `scenarios/g4-show.json`（Wipe 左→右软边 0.1、Stinger = 9 号第 12 拍换底都在节目文件里；切换面板还没有这些参数的控件，归 W3-E2 / prompt 63）。
面板上 Wipe / Zoom / Stinger 三个按钮 = 把类型写进状态 + 立刻起一次 auto 转场（时长用面板的时长预设）。

- [ ] 点 **Wipe**：新画面从左向右擦入（时长预设 0.5 s = 30 拍），边缘柔 10% 宽；PGM 标题在结束那一拍才换；按钮转场期间高亮。
- [ ] 点 **Zoom**：新画面从中心放大到满幅，旧画面在四周；无黑帧。
- [ ] 点 **Stinger**（9 号图片输入在节目里；若第 1 条另加了图片输入，Stinger 参数只能改节目文件）：蓝色横幅 + 立柱叠在最上层 30 拍，第 12 拍时底下的画面从旧切到新（横幅遮不住的顶部区域能看见切换点），结束后叠层消失。
      静态 PNG 只是"延迟 Cut + 一层图"；要动画 stinger 需要文件输入 + 引擎"转场开始时从头播"（W3-B 报告 §3 第 2 条，未做，见 reports/G4.md §3）。
- [ ] **T-bar 手推 Wipe**：点过一次 Wipe 后（类型留在状态里）拖 T-bar 到 25% / 50% / 75% 停住：擦边分别在画面 1/4、1/2、3/4 处（软边居中于该位置）；推到顶对调并回弹；中途松手停在原位。
- [ ] Cut / Fade 仍正常（回归）：空格 Cut 无过渡帧，Fade 30 拍平滑。

## 5. 多画面窗口拖到外接屏；外部输出选 Aux 输入

- [ ] 窗口 › 多画面（或底栏"多画面"）→ 16:9 独立窗口出多画面（自定义布局：上 PVW / PGM，下 8 路 4×2，每格 tally 边框 + 名字，PGM / PVW 格有安全框，输入格右侧有电平表占位条）。
      拖到外接屏（有的话）/ 全屏：画面连续，状态行 **missed_render 不增**；关掉再开位置记住（Show.layout["multiviewWindowFrame"]）。
      没有外接屏：内置屏上全屏 10 s 看丢帧不增，外接屏部分记 BLOCKED-硬件。
- [ ] 输出 › 外部输出 › <显示器> › **输入 n（Aux）**：该屏全屏显示第 n 路（画的是多画面纹理里它那一格，分辨率约 470×260 放大——W3-C 报告 §3 第 1 条，全分辨率 Aux 归属待定）；再选一次 = 关（菜单项打勾状态跟着变）。
      选 PGM：全屏 PGM，拖动主窗口 10 s，missed_render 不增。Esc 关闭。
- [ ] 输出 › 外部输出… 设置页：列表里有刚开的那一路（显示器 / 来源可改，"关闭"= 删输出）。节目另存再打开：外部输出跟着恢复（externalDisplay 的 enabled 不会被清，只清录制 / 推流）。

## 6. 虚拟摄像头在 FaceTime 里可见（有签名时）

- [ ] 无 Team ID（本机 G4 时的情况）：输出 › 虚拟摄像头 › 安装 / 激活扩展… → 状态行提示 "Missing entitlement com.apple.developer.system-extension.install … BLOCKED-签名"，App 不崩；输出 › 虚拟摄像头 › 启用 → 状态显示"找不到虚拟摄像头设备（扩展未安装 / 未激活）；已丢 N 帧"，N 在涨（消费者在跑）。**记 BLOCKED-签名。**
- [ ] 有 Team ID：`DEVELOPMENT_TEAM=<TeamID> make gen build-app`，把 Switcher.app 拷到 /Applications 再起 → 安装 / 激活扩展 → 系统设置 › 通用 › 登录项与扩展 里允许 → 状态"已激活" → 启用输出 → FaceTime / QuickTime 新建影片录制里选 "Switcher" 摄像头：能看到 PGM，帧号块在走、闪光每秒一次；关掉输出后 FaceTime 里变成占位画面（深灰 + 移动白条）。
      L1（W3-C：`VirtualCameraAppTests.testL1_virtualCameraEgress_requiresSignedExtension`）签名后再跑一次填数：____ 帧（≤ 3）。

## 7. Companion 六项（C5）

服务端二选一：
- App：偏好设置 › 第三方 API 兼容层：打开、端口 8099（HTTP 8088 固定）→ 应用并重起引擎；法律提示读一遍。
- headless：`swift build -c release --package-path Tools/switcher-headless && $(swift build -c release --package-path Tools/switcher-headless --show-bin-path)/switcher-headless run --show scenarios/g4-show.json --duration 1800 --audio-device null --compat --api`

Companion（Bitfocus Companion 3.x，本机没装：`brew install --cask companion` 或官网下载）加一个 "vMix" 类型连接指到 127.0.0.1:8099，按 docs/integrations/companion.md §1 配一页按钮：

- [ ] Cut：PGM / PVW 对调，按钮 tally 颜色跟着换（PGM 红、PVW 绿）。
- [ ] Fade（500 ms）：0.5 s 过渡，过渡期间两个按钮都亮红。
- [ ] Overlay 1 开 / 关 / In / Off：画中画出现 / 消失，Overlay 按钮琥珀色。
- [ ] Record 开 / 关：底栏"● 录制中"，按钮红。
- [ ] Stream 开 / 关（节目里要先有一路推流目的地，例如 `rtmp://127.0.0.1:1935/s1` + 另一终端 `mediamtx scripts/mediamtx.yml`）：按钮蓝。
- [ ] Tally 反馈：切换后 ≤ 250 ms 按钮颜色变（Companion 轮询 XML 250 ms + TALLY 订阅）。
      六项在 headless 上的自动化版本 `scripts/apitest/c5-companion.py --url 127.0.0.1:8099` 已过（W3-D）；真 Companion 没装前记 **BLOCKED-人工**。

## 8. 录 ISO 4 路，QuickTime 打开各文件对齐

- [ ] 8 路合成源（或第 1 条加的几路）的节目：底栏 "ISO…" 勾 1、2、3、4 号 → 输出表多四路（`{show}-{date}-{time}-{output}` 模板）；底栏"录制"→ "● 录制中 ×5"（PGM + 4 路 ISO 同一拍起）。对着有音频的路拍手 / 用合成源的 click。60 s 后停。
- [ ] QuickTime 逐个打开 5 个文件：时长相同（± 1 帧）；同一秒的闪光帧 / click 在各文件里同一时刻（逐帧 ← → 看，A4 ≤ 1 帧；gate4 的自动 A4 用 frameprobe 判到 ms：`frameprobe av <pgm.mov> <iso1.mov> … --fps 60 --markdown`）。
- [ ] 30 fps 的那路 ISO 文件每帧重复一次（与 PGM 一样按节目拍网格）；ISO 文件的音轨是该路自己的（推子后、AFV 前，G3 定的口径）。
- [ ] 磁盘保护顺手看：把录制目录指到一个快满的小镜像（`hdiutil create -size 50m -fs APFS -volname tiny tiny.dmg && hdiutil attach tiny.dmg`），起录制 → ≤ 2 s 提示"磁盘剩余 … 低于下限"，只停录制，推流 / 画面不受影响（S7）。

## 汇总：BLOCKED 项与解锁条件（G4 时的本机）

| 项 | 状态 | 解锁条件 |
|---|---|---|
| DeckLink L1 / L2 / S5、第 1 条的有卡部分 | BLOCKED-硬件 | UltraStudio / Mini Recorder + Desktop Video 驱动 + 任意 SDI / HDMI 源；正式 SDK 解压到 ~/SDKs/DeckLink 后重编（现在用的是 NDI SDK 示例里的 10.11.2 头） |
| 外接屏（多画面窗口拖过去、外部输出 L2 秒表法） | BLOCKED-硬件 | 接一块 HDMI 显示器（L2 还要摄像头 + 毫秒秒表） |
| 虚拟摄像头激活 / FaceTime 可见 / L1 | BLOCKED-签名 | Apple Developer Program 的 Team ID（`DEVELOPMENT_TEAM=… make gen`），从 /Applications 运行，系统设置里允许扩展 |
| Companion 六项 | BLOCKED-人工 | 装 Bitfocus Companion，按 docs/integrations/companion.md 配；服务端用 App 偏好设置开关或 headless `--compat` |
| Stream Deck 插件端到端 | BLOCKED-硬件 | Node ≥ 20.5 + Stream Deck 软件 / 硬件（docs/integrations/stream-deck.md） |
| 纯音频设备输入 | 未实现（W3-A 范围外） | 需要一个 AudioDeviceInput（Core Audio 输入 → 环），归属待定（reports/G4.md §3） |
| 摄像头 / 屏幕录制授权相关的自动测试 | BLOCKED-权限 | 从 Terminal.app 跑 `make test-app`（Claude 的 Bash 起的 xcodebuild 拿不到 TCC） |
