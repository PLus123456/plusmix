  • 串行骨架：环境（你）→ P0 仓库骨架 → P1 契约冻结 → G1 人工复审 → 【W1 五路并行】→ G2 = M0 → 【W2 五路并行】→ G3 = M1 + M2 + M3 + M5 → 【W3 五路并行】→ G4 = M4 + M6 → 【W4 三路并行】→ G5 = M7 发布门槛。

1现状盘点

1.1 读了什么

文件内容用在哪
导播台设计方案.md架构、线程模型、数据模型、选型、里程碑 M0–M7拆分的骨架，每个 prompt 的"先读"
导播台测试标准.mdV / A / E / L / S / C 六类指标、工装、测法、阈值、报告模板每个会话的验收 ID，检查点的通过标准
导播台后续方案.md第二版功能本期只要求架构留位置：Frame 像素格式含 UYVY、Renderer 留转场接口、总线枚举可扩
Vmix macOS风格界面设计.zipClaude Design 画布（React 组件）+ 三张 vMix 截图（主界面、Input Select、Recording Setup）W2-B / W3-E 的布局参考，只借布局不借品牌

1.2 这台机器

Apple M5 Max / 128 GB / macOS 26.4。缺 Xcode、Command Line Tools、Homebrew、ffmpeg、MediaMTX、NDI SDK、DeckLink SDK，硬件只有内置摄像头。这台机器远强于规格里的目标机（M1 Air 8 GB）：性能阈值在这里过了不代表在 Air 上过，发布前要借一台 Air 跑 L5。

1.3 规格与 UI 稿的冲突和缺口

prompt 里已按默认值处理，第 7 节等你拍板。

  1. 品牌。UI 稿标题写着 "vMix Pro" / "vMix for Mac"，设计方案 §0 明确产品名不能带 vMix。→ 只借布局，文案全换。
  2. 转场集合。稿子是 Cut / Fade / Merge / Wipe / Fly / Quick Play，规格是 Cut / Fade / Wipe / Zoom / Stinger。→ 按规格。
  3. Tally 颜色。稿子用 vMix 的绿 = PGM、橙 = PVW。→ 改用广播惯例红 = PGM、绿 = PVW。
  4. 测试图案帧号位数。测试标准写 16 块 12 位，12 位 68 秒就回绕，8 小时长稳会歧义。→ 32 块 28 位 + 4 位校验，这是 P1 里唯一允许偏离测试标准的地方。
  5. 输入类型与录制格式列表。稿子里是 vMix Windows 版的（DVD、PowerPoint、AVI、WMV）。→ 按规格 §6 和 §8。
  6. HaishinKit 接哪一层。规格自己说"做到这步再验证"。→ W2-D 第一步就是 spike，三选一写结论。
  7. vMix 兼容层法律灰区。→ 独立 target、默认关、文档顶部带提示。
  8. 虚拟摄像头与公证需要付费 Apple Developer 账号，W3 之前要有。
  9. 硬件缺口导致一批测试只能标 BLOCKED，见第 6 节。

2.1 可以提前开的会话

波次是安全排法。有余力时这三处可以提前，不会打架：W2-C 控制层只依赖契约和状态机，W1-B 一合并就能开；W3-B 合成二期只依赖 W1-C，G2 一过就能开，和 W2 并行；W3-D 只依赖 W2-C，W2-C 合并即可开。

真设备（内置摄像头、扬声器）同一时刻只能给一个会话用：W2-A 和 W2-E 的真设备测试要错开跑。

3流程与依赖

上面的 run of show 是主线。逐个会话的依赖见第 2 节"依赖"列；三处可提前的会话见 2.1。规则只有两条：闸门不过不进下一波；同一波内的会话互不依赖。

4检查点：在哪、怎么检查

检查点会话的规矩：只合并、只跑、只写报告。单个包超过 50 行的改动不许在检查点做，写成 reports/issues/ 退回原会话。每个检查点固定产出 reports/GN.md（测试标准 §7 模板）和 baselines/gN-机器.json。你每个检查点的人工时间控制在 15–30 分钟。

5会话怎么跑

  1. 一个会话 = 一个 prompt。新开 Claude Code 会话，用下面卡片上的"复制 前言 + 本段"，粘贴，开头加一句"请在独立的 git worktree 里工作"。
  2. 并行。同一波次的会话各开一个窗口同时跑。它们只动各自目录，check-ownership 会拦越界。
  3. 不 push、不 merge。功能会话只在自己分支提交。检查点会话按 prompt 里的顺序合并。
  4. 报告。每个会话结束必有 reports/分支名.md。你只看三块：测试表、BLOCKED 项、契约疑问。
  5. 契约变更。任何会话提出 docs/contract-changes/*.md，你批了之后由契约会话改，其他会话 rebase。
  6. 推理档位。P1、W1-B、W1-C、W1-D 用最高档位；界面和文档会话可以低一档。
  7. 真设备互斥。W2-A 和 W2-E 用摄像头 / 声卡的测试错开。
