PlusMix User Manual

PlusMix (code name Switcher: the modules and command-line tools keep that name) is a multi-camera production switcher that runs natively on Apple Silicon Macs: numbered inputs, Program / Preview monitors, Cut / Fade / Wipe / Zoom / Stinger transitions, four overlay channels, four audio buses, and outputs to recording, streaming, NDI® (NDI® is a registered trademark of Vizrt NDI AB), a second display, a virtual camera and a multiview. This manual is for operators. How it works inside is in the design spec (repository: docs/spec/导播台设计方案.md) (Chinese); how it is verified is in testing (repository: docs/testing/en/README.md).

The interface is described as it looks after the 0.1.x redesign (toolbar, three-part bottom bar, a single Settings window…); for the old 0.1.0 interface see docs/ui-study/03 (repository: docs/ui-study/03-目视检查.md) (Chinese).

First run

  1. Build and open (Xcode required; see the repository README (repository: README.md)):
make gen build-app && open .build/DerivedData/Build/Products/Debug/PlusMix.app
  1. Show › Open… (or Open in the toolbar) and pick Samples/event/event.switcher.json: four synthetic cameras, a multiview and four ISO recordings, all configured.
  2. Press 2 to put input 2 on Preview, Space to cut, Return to run the selected transition (Fade by default), F to fade to black; or click Transition or Cut on a cell.
  3. Click Record in the bottom bar to record into ~/Movies/PlusMix/活动/; click again to stop (it asks first).
  4. Input › Add Input… (⌘I) to connect your camera. macOS asks for camera / microphone access the first time; screen recording access must be granted manually in System Settings (Troubleshooting › Permissions).

Version and language

This manual matches PlusMix 0.1.x (see the status in the repository README (repository: README.md)). The interface is available in Simplified Chinese and English and follows the system language (Settings › General › Language overrides it after reopening the app). Menu names below use the English interface; the Chinese names are in the Chinese pages.
