快捷键、MIDI 与控制面板

所有控制方式发的都是同一套命令（概念 › 切换是怎么发生的），所以快捷键、MIDI、Stream Deck、Companion、脚本可以混用，状态永远一致。

默认快捷键表

主窗口在前时生效（输入框里打字时不触发）；输入设置、叠加设置、音频设置这几个窗在前时按键也照常切画面。设置窗在前时这一版不转发按键（点一下主窗口再按）。

键动作
1 … 9、0把 1–10 号输入选到 PVW（0 = 10 号）
⇧1 … ⇧0直切 PGM（PVW 不变）
空格Cut
回车执行当前转场（按已选的类型 / 时长，默认 Fade 30 拍）
FFTB 开 / 关
⌥1 … ⌥4执行转场 1–4（这一版四个都 = 执行当前转场，和回车一样）
⌃1 … ⌃4叠加 1–4 开 / 关（只开关、不换输入：通道还没指定输入时开了也没有画面）
  • 录制 / 推流没有默认键：快捷键停录制 / 推流一律不弹确认，误按一个键就停了。要的话自己加（改表），选"全部录制输出开 / 关"之类的动作。
  • 界面锁没有默认快捷键：只能点底栏最右的锁，或 窗口 › 锁定界面。
  • ⌃1–⌃4 与系统的"切换到桌面 1–4"同键：在 系统设置 › 键盘 › 键盘快捷键 › 调度中心 里打开了那几项，这几个键会先被系统拿走；⌥1–⌥4 没有系统占用。
  • 帮助 › 快捷键一览：按当前的表生成一页（按键 / 动作 / 备注），用浏览器打开，可以打印出来贴在控制台上；改了表再点就是新的。

菜单快捷键（AppKit 标准）：⌘N 新建、⌘O 打开、⌘S 保存、⇧⌘S 另存为、⌘I 添加输入、⇧⌘I 输入设置（PVW 上那一路）、⌘F 搜索输入、⌘, 设置、⌘M 最小化、⌘Q 退出（录制 / 推流在跑或有没保存的改动时先问）。菜单"切换"右边灰字写的是快捷键表里对应的键，只是显示——按键由快捷键表处理，改了表菜单跟着变。

改表

设置 › 快捷键（PlusMix › 快捷键…）：每行一条——启用（勾）、组合键（直接打字，或点"录键"再按）、动作（一句话摘要，点开选动作面板）、备注，行尾"编辑 JSON… / 复制 / 删除"。

  • 顶上一个搜索框（按键 / 动作 / 备注都能搜）；底下"加一条"、"恢复默认表"、"保存"。"复制"在下面插一行同样的动作，组合键空着等你录。
  • 同一组合键在启用的行里绑两次："保存"旁边写"n 处冲突"、存不了；停用的行不派发、也不算冲突。
  • 新加的行没有动作，要先选一个才能存（"第 n 行还没选动作"）——不会悄悄变成别的命令。
  • 改完要点"保存"；有没存的改动时关窗或切页会先问"保存 / 取消 / 放弃改动"。页底写着表文件的位置。
  • "编辑 JSON…"：直接写一条命令（顶层键是命令名，与 HTTP API 的 command 同一个写法），应用时校验，认得出的会回到对应的动作。

选动作面板

点一行的动作按钮弹出：

  • 顶部搜索（打开就能打字，跨组搜动作名、说明和 API 键名）；左栏分组：切换 / 叠加 / 音频 / 输出 / 输入 / 节目 / 界面 / 全部 / 最近用过。
  • 右栏每个动作一行：名字 + 一句说明 + 小字 API 键名（组合动作写出会发哪几条，例如"previewAndTransition → setPreview + autoTransition"）。
  • 下面是按参数生成的表单：输入 = 下拉（"输入 3「名字」"），另有"当前 PVW / 当前 PGM"（按下那一刻 PVW / PGM 上是哪一路就是哪一路）；时长按秒（0.5 / 1 / 2 + 自定义）；叠加通道 1–4；输出只列合适的那几类；总线四选一；开关类是"开 / 关 / 切换"三段。
  • 最下面"按下时会发什么（按现在的状态）"：按当前节目算出来的那几条命令，就是按下时进命令总线的那几条。
  • 默认只列操作员用的动作。整条替换节目 / 输入设置 / 输出设置、增删输入输出这类要勾"显示整条替换类（高级）"，或选"高级：手写 JSON…"（存之前校验）。

几种值得知道的动作：

动作说明
选进 PVW 并转场先把这一路选进 PVW，再按已选的转场推上 PGM（一键两条命令，按顺序发；前一条被拒——比如那一路已经删了——后一条就不发；转场进行中按下，两条都被状态机忽略，什么都不变）
Fade按秒（存成毫秒）：节目换了帧率时长不变。旧表里按拍存的 Fade 照读照用，选动作面板里写"Fade（按拍存，旧）"

输出开关、一类输出全部开 / 关NDI® / 外部显示 / 虚拟摄像头 / 多画面里的一路，或某一类一起开关

显示 / 隐藏调音台、多画面窗口开 / 关、多画面窗口全屏界面动作：只在本机的 App 里做，不进命令总线（API 看不到）

hotkeys.json

表存在 ~/Library/Application Support/PlusMix/hotkeys.json（节目文件之外，换节目不变）。格式：

{
  "version": 1,
  "bindings": [
    {"key": "1", "action": {"command": {"setPreview": {"input": 1}}}, "note": "PVW 选 1 号"},
    {"key": "shift+1", "action": {"command": {"setProgram": {"input": 1}}}, "note": "直切 PGM 1 号"},
    {"key": "space", "action": {"command": {"cut": {}}}, "note": "Cut"},
    {"key": "return", "action": {"command": {"autoTransition": {}}}},
    {"key": "f", "action": {"toggleFTB": {}}},
    {"key": "ctrl+1", "action": {"toggleOverlay": {"channel": 1}}, "note": "叠加 1 开关"},
    {"key": "g", "action": {"fadeMs": {"durationMs": 750}}, "note": "0.75 秒 Fade"},
    {"key": "alt+shift+3", "action": {"previewAndTransition": {"input": 3}}},
    {"key": "m", "action": {"ui": {"name": "toggleMixer"}}, "note": "显示 / 隐藏调音台"},
    {"key": "cmd+alt+r", "action": {"recordAll": {"mode": "toggle"}}, "note": "全部录制（按了不问）", "enabled": false}
  ]
}
  • 组合键写法 ctrl+alt+shift+cmd+<键>，顺序随意，也认 ⌘⌥⌃⇧ 前缀和 command / option / control 全称；键是单个字母 / 数字 / 符号或命名键： space, return, escape, tab, delete, forwarddelete, up, down, left, right, home, end, pageup, pagedown, f1 … f20。
  • 动作写法：{"command": {<命令>}}（命令的 JSON 与 API 相同，API 参考（仓库：docs/api.md）），或下表这些开关 / 组合动作。开关类的 mode 是 "on" / "off" / "toggle"，不写 = 切换；输入可以写编号，也可以写 "preview" / "program"（按下那一刻 PVW / PGM 上的那一路）。
  • "enabled": false 只在停用的行上写；没有这个键 = 启用。旧文件照读。
  • 文件读不出来（JSON 错、冲突）时用默认表并在状态行提示。
动作JSON
FTB / AFV 开关{"toggleFTB": {}}、{"toggleAFV": {}}
叠加开关 / 换成这一路并打开 / 全部关闭{"toggleOverlay": {"channel": 1}}、{"overlayInput": {"channel": 2, "input": "preview"}}、{"overlaysOff": {}}
静音开关{"toggleMute": {"input": 2}}
某一路录制 / 推流开始停止{"toggleRecord": {"output": 1}}、{"toggleStream": {"output": 2}}

MIDI

设置 › MIDI（PlusMix › MIDI 映射…）：CoreMIDI，所有在线设备都监听，页上列出当前的 MIDI 源。每行一条：启用、触发（Note / CC / 14-bit CC、通道、号）、"Learn"（动一下推子 / 按一下键就填好触发）、动作（同一个选动作面板）、备注。同样有搜索、加一条、复制、删除、编辑 JSON…，改完点"保存"。

触发能接的动作
CC（7-bit，通道 1–16、控制器 0–127）只接推杆类：T-bar（到两端提交并换向，像真推杆）、输入增益推子、总线增益推子（值 0–127 线性映射到设定的 dB 范围）
14-bit CC（控制器 0–31 为粗、+32 为细）同上，推杆更平滑
Note（按下，力度 > 0）按钮类：与快捷键相同的动作（命令、开关、组合动作、界面动作）

存的时候查"动作合不合触发"（Note 接按钮动作、CC 接推杆类），不合就报"第 n 条的动作不合触发"、不存。映射表在 ~/Library/Application Support/PlusMix/midi.json：

{
  "version": 1,
  "mappings": [
    {"trigger": {"cc14": {"channel": 1, "controller": 1}}, "action": {"tbar": {}}, "note": "推杆"},
    {"trigger": {"cc": {"channel": 1, "controller": 7}}, "action": {"busGain": {"bus": 0, "minDb": -60, "maxDb": 0}}},
    {"trigger": {"cc": {"channel": 1, "controller": 16}}, "action": {"inputGain": {"input": 1, "minDb": -60, "maxDb": 12}}},
    {"trigger": {"note": {"channel": 1, "note": 60}}, "action": {"action": {"command": {"cut": {}}}}},
    {"trigger": {"note": {"channel": 1, "note": 61}}, "action": {"action": {"toggleFTB": {}}}}
  ]
}

Note 的 "action": {"action": …} 里面就是上面 hotkeys.json 的动作写法。默认是空表（没有出厂映射，恢复默认 = 清空）；midi.json 读不出来时也用空表，不提示。设备拔掉再插回会自动重新监听；App 运行中新接的设备也会被发现。

Stream Deck、Companion、tally、脚本

  • Stream Deck：官方 SDK 插件（按钮 = 命令，按钮颜色 = tally），安装与按钮表见 docs/integrations/stream-deck.md。
  • Bitfocus Companion：走本地 API 的接法（Generic HTTP / WebSocket 模块）见 API 示例（仓库：docs/api/examples.md）；用现成第三方面板配置走兼容层的接法见 docs/integrations/companion.md。 Companion 在另一台机器上时，设置 › 远程控制 里把兼容层改成"允许局域网"、应用并重起引擎，把页上显示的地址填进 Companion。
  • 外部 tally 灯：只读的 WebSocket / HTTP tally 流，在 设置 › Tally 里打开（默认关，端口默认 8766），页上有可以直接复制的地址；协议见 docs/integrations/tally.md。也可以读本地 API 的 GET /api/v1/tally。
  • 脚本 / 自动化：HTTP + WebSocket 的本地 API，docs/api/README.md。默认只听 127.0.0.1:8765；设置 › 远程控制 里改"仅本机 / 允许局域网"、端口和 token。
