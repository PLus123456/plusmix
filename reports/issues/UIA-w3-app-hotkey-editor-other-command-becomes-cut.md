# 快捷键编辑器：把一行切到"其他命令"再保存，会悄悄变成 Cut；MIDI 面板这类行显示空白

归属会话 / 分支：App 会话（W3-E 系）；`App/Sources/Settings/HotkeyEditorPanel.swift`、`MIDIMappingPanel.swift`
发现于：界面对照调研 UIA，提交 c836cce；R5-M04、R8-S35，核对 VF5 属实（成因行已更正）
现象：编辑器只有 12 种动作（MIDI 11 种）+ 一个整数参数；从 hotkeys.json 读来的"其他"命令能保留，但在编辑器里把某行切到"其他命令"时没有地方填命令，保存后这一行变成 Cut（空格同款），用户不会察觉；MIDI 映射面板里"其他"动作的行，动作下拉显示为空。Fade 的参数单位是拍，不是秒 / 毫秒。
复现步骤：切换 › 快捷键… 选一行，动作改成"其他命令"，保存，重新打开：变成 Cut。
严重级：S2（快捷键表被静默改写，现场按下去执行的是 Cut）
猜测原因：`HotkeyEditorPanel.swift:47`、`:196`、`:77`（`case .other: .command(other ?? .cut)`）；`MIDIMappingPanel.swift:264-270`（选项里滤掉了"其他"）；没有用例覆盖。
建议改法：短期把"其他命令"从可选动作里拿掉（只保留读进来的原样显示），或切过去时弹 JSON 编辑框、校验后才保存；长期换成统一的动作选择器（分类 + 搜索 + 参数表单，01a-改动总表 N 区）。补一条用例钉住"其他命令不会被改成 Cut"。
