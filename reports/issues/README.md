# reports/issues/ —— 退回原会话的问题单

检查点会话（G2–G5）只合并、只跑测试、只写报告；发现功能 bug 或单个包超过 50 行的改动需求时，不在检查点里修，写一张问题单退回原会话。

文件名：`<检查点>-<归属会话>-<短标题>.md`，例如 `G2-w1-core-missed-render-drift.md`。

内容固定：
```
归属会话 / 分支：
发现于：检查点 / 场景文件 / 提交号
现象：指标 ID、数值、阈值（引用 stats.jsonl 或 frameprobe 输出路径）
复现步骤：
严重级：S0–S3（测试标准 §6）
猜测原因（可选）：
```
原会话修完在报告里引用这张单子的文件名。
