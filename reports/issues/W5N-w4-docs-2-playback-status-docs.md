## 要改的点

1. **格子第一行**（输入条与格子那一节）：× ｜ 转场 ｜ Cut ｜ ⏮ ｜ ▶/⏸ ｜ 🔁。后三颗是图标、只对视频 / 音频文件输入亮（别的输入灰着，提示"只对视频 / 音频文件输入"）。
   - ⏮ 回到开头：播着就从头播，暂停着就停在第一帧（定位与暂停各管各的，提案 021）。
   - ▶/⏸：播着显示 ⏸（点 = 暂停：画面停在这一帧，仍每拍出帧，不算无信号）；暂停中显示 ▶、按钮高亮（点 = 继续）；播完不循环时显示 ▶（点 = 从头播）。
   - 🔁 循环（原来是写着"循环"两个字的按钮，最小格子放不下六颗字按钮，改成图标）：开 = 循环；**关 = 播完停在最后一帧**（2026-10-10 裁定 ②；要黑场去输入设置 › 来源改"播完"）。
     播完之后（已经停在末帧）再打开循环 = 当场从头接着循环。
   - 右键（文件输入才有）：播放 / 暂停、回到开头、循环（打勾）、**切上 PGM 时从头播**（打勾，随节目保存）。
2. **切上 PGM 时从头播**：这一路切上 PGM 的那一拍（Cut / 转场做完 / T-bar 推到顶 / API setProgram）从头播，首帧晚几拍（实测见 reports/w5-playback-status.md §2）；在 PVW 上预览时不动；暂停中切上去 = 回到第一帧但仍暂停。
3. **输入设置 › 来源**（文件输入）：只改"播完"或"播放速率"当场生效、不重建这一路（接着播），不用点"应用来源"；换文件 / 换类型照旧要点"应用来源"（这一路重建，画面断一下）。下面多一节"播放"：▶ 播放 / ⏸ 暂停、⏮ 回到开头、切上 PGM 时从头播。
4. **推流 / 录制状态面板**（新）：底栏推流 ▴ 的"推流状态…"（原来打开推流页）、录制 ▴ 末尾的"录制状态…"、输出设置 › 推流页顶上的"推流状态…"、录制页的"录制状态…"都开它；菜单栏"输出 › 推流 ▸"里同一项。
   - 推流页：每个目的地一行——名称 / 状态 / 码率 / 丢帧 / 重连（成功连回来的次数）/ 时长 / 断线（连上之后掉线的次数）/ 最后错误（推流模块打的那一行原文：鉴权失败有三种写法，见 reports/w5-stream-auth.md §5 第 3 条）。
   - 录制页：名称 / 状态 / 时长 / 码率 / 帧数 / 丢帧 / 剩余空间 / 最后错误。
   - 下面"事件"：带时间的状态变化（连接中 → 推流中 → 断开：原因 → 重连中（第 n 次）→ 重连上 / 已停止 / 失败：原因），由每秒一次的统计推出，一秒内来回的看不到；窗口关着也记，换节目 / 重新开引擎清空。
   - 底部"视频延后 n ms"（带效果的监听同步，W1-B4）只在有延后时出现；"显示日志…"= 帮助 › 打开诊断文件夹。
5. **时长**：底栏录制 / 推流按钮在录 / 在推时写"● 录制 01:02:05""● 录制 00:14:22（3 路）""● 推流 00:10:00（2/3）"（时长读统计里的 uptime_s，多路取最长的；推流的时长含重连期间）；工具条右侧同一份；录制 ▴ 每一行"名字 · 录制中 · 01:02:05"；输出设置 › ISO 页的表多一列"时长"。英文界面写"● REC 01:02:05""● LIVE 00:10:00"。
6. **状态行**：原来的"编码跳帧 n · 码率 x"换成"编码滞后跳帧 n · 录制 x Mb/s · 推流 y Mb/s"——录制和推流分开写（原来两个都开时只看得到录制的码率），多路时各给码率最低的那一路（退避中的推流码率是 0，就是它）；"编码滞后跳帧"= 编码器跟不上、在编码之前跳过的帧（累计；不是"编码器占用"）。NDI 发送的原始码率不进这两项。
7. **推流鉴权的两种写法**（输出设置 › 推流 › 鉴权…，2026-10-10 裁定 ①）：
   - "写法"二选一：**Adobe（user:pass@）**——Wowza / Nimble / FMS 和要鉴权的 CDN 入口；**查询串（?user=&pass=）**——MediaMTX / SRS / nginx-rtmp 这类自建服务器，参数名可改（默认 MediaMTX 的 user / pass；SRS / nginx-rtmp 按服务器上鉴权回调的规矩填）。
   - 两种互斥：换写法保存时另一种的账号会被去掉；用户名留空 = 两种都去掉。
   - 地址框里 user:pass@ 与查询串里 user / pass / password / key / token / secret / passphrase / streamid 等参数的值都打码成 •••（与日志、诊断包同一份名单）；编辑地址时打码的值原样留着就保住原值。参数名不在名单里时鉴权表会提醒"地址框和日志里会显示明文"。
   - 地址框下面那一行写"鉴权：用户 xxx（密码已设）"或"鉴权（查询串）：用户 xxx"。
8. **API 文档**（docs/api.md 不用重生成：没有加命令）：`setPlayback` / `seekPlayback` / `setInputSettings` 的 `playback.restartOnProgram` 现在界面上有入口了，docs/api 里讲文件播放的地方可以链到手册第 1、2 条；`Stats.encoder[].uptime_s / disconnects / last_error / attempt` 界面上读的位置见第 4、5 条。
