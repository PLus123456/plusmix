## 3. 没做的和原因

- **整仓 `make test`、`make gate3`、`make gate3-net`、`make gen build-app`**：Xcode 27 没装 Metal 工具链（需要下载约 688 MB 的系统组件，按约定由用户做）。命令：
  `xcodebuild -downloadComponent MetalToolchain`（可能还要 `sudo xcodebuild -runFirstLaunch`，`-checkFirstLaunchStatus` 返回 69）。装好后：`make test`（整仓）→ `make gate3-run` → 另一终端 `sudo scripts/netem.sh serve` → `make gate3-net`。
- **App 接线**（摄像头 / 文件 / 录制 / 推流 / 音频 / API，约 170 行）：超过检查点 `~App/:50` 额度，没做；选项见 reports/G3-notes.md §7 第 3 条。人工清单里给了 headless 等价物。
- **契约提案落地**（001 / 002 / 004 / 005）：不是检查点的事；建议一次契约会话一起落地（G3-notes §7 第 2 条）。
- **W2-E 退回 W1-D / W1-E / W1-A 的修改**：写在 G3-notes §7 第 5 条，等用户定。
